# Tier 7.34 — True 3D Gizmo Handles (TransformControls → governed commit)

## Purpose (LOCKED)
Replace 2D drag pad with real 3D gizmo handles in the Three.js viewport:
- translate arrows/planes
- rotate rings
- scale boxes

## Invariants
1. Dragging is UI-only preview. No backend calls during drag.
2. On drag end (mouse up), exactly ONE governed commit occurs:
   /assistant/proposals/evaluate → /assistant/proposals/apply
3. No direct snapshot mutation on client.
4. SelectionStore.selectedId is the only target_id source.
5. Deterministic mapping:
   same start transform + same drag result => same payload.

## Behavior
- attach gizmo to selected object group (obj:<objectId>)
- mode = translate|rotate|scale
- during drag: setGizmoPreview(...)
- on release: clear preview, send commit payload.

## Forbidden
- multiple commits per drag
- auto-select on gizmo use
- editing completed snapshots
