# Tier 7.75 — Edit Mode Flow

## Purpose (LOCKED)
Automatically enter edit mode when opening Studio.

## Behavior

On studio load:

1. Fetch snapshots
2. If draft exists → use it
3. Else → create draft from latest completed snapshot
4. Acquire lock
5. Set active snapshot
6. Enable editing tools

## Invariants

- Only ONE active draft
- Lock required for editing
- No manual "enter edit mode"

## Forbidden

- multiple drafts
- editing without lock
