# Tier 6S.7 — Batch Runner (Experiment Engine)

## Purpose (LOCKED)
Run N scenarios against a snapshot in one command, producing N immutable artifacts and indexed runs.

## Invariants (NON-NEGOTIABLE)
1. No snapshot mutation.
2. Artifacts immutable.
3. Batch input deterministic ordering:
   - scenario_ids sorted asc
   - template_keys sorted asc
4. Batch is auditable: batch record created + run rows created.
5. Baseline implementation may execute synchronously; API shape must support future async.

## Entities
### SimulationBatch
- id: int
- project_id: int
- snapshot_id: int
- engine_version: string
- status: queued|running|succeeded|failed
- scenario_ids_json: [int]
- template_keys_json: [string]
- run_ids_json: [int]
- artifact_ids_json: [int]
- error: string|null
- created_by: int
- created_at: timestamp

## API (Additive)

### POST /simulation/batches
Body:
{
  "snapshot_id": int,
  "engine_version": "pseudo-v1",
  "scenario_ids": [int, ...],        # optional
  "template_keys": ["accel_0_60_v1"] # optional
  "template_overrides": { "<template_key>": {...} } # optional
}
Rule: must provide at least 1 of scenario_ids or template_keys.

200:
{
  "batch_id": int,
  "status": "queued"|"running"|"succeeded"|"failed",
  "run_ids": [int],
  "artifact_ids": [int]
}

### GET /simulation/batches/{batch_id}
200:
{
  "batch_id": int,
  "status": "...",
  "snapshot_id": int,
  "engine_version": str,
  "run_ids": [int],
  "artifact_ids": [int],
  "error": str|null
}

## Forbidden
- mutating snapshot
- changing artifact schema
