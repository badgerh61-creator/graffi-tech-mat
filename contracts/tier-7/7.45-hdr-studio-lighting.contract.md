# Tier 7.45 — HDR Studio Lighting + Environment (Viewer-only)

## Purpose (LOCKED)
Make the viewport feel like a real studio by adding:
- HDR environment lighting (PMREM)
- simple studio 3-point lighting
- deterministic defaults

## Inputs
- viewer render settings (UI-only)
- optional HDR url (static asset path)

## Behavior
- In viewMode=studio:
  - environment map enabled
  - tone mapping enabled
  - physicallyCorrectLights enabled
- In other view modes:
  - may keep env or disable (deterministic)

## Invariants
- No backend calls required
- No snapshot mutation
- If HDR fails to load, fallback to neutral gray env + lights

## Forbidden
- non-deterministic random lights
- per-frame recreation of PMREM/env
