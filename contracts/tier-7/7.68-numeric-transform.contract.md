# Tier 7.68 — Numeric Transform Input

## Purpose (LOCKED)
Allow precise numeric editing of object transforms via inspector.

## Scope
- position (x, y, z)
- rotation (x, y, z in degrees)
- scale (x, y, z)

## Selection Behavior

### Single Selection
- edits apply directly to selected object

### Multi Selection
- edits apply relative to each object's current value
- absolute mode (future tier)
- Tier 7.68 uses delta-based editing

## Tools (Governed)

SCENE_SET_OBJECT_TRANSFORM
payload:
{
  "object_id": "obj-...",
  "transform": {
    "pos": { "x": number, "y": number, "z": number },
    "rot": { "x": number, "y": number, "z": number },
    "scale": { "x": number, "y": number, "z": number }
  }
}

SCENE_BULK_OFFSET_TRANSFORM
payload:
{
  "object_ids": ["obj-..."],
  "delta": {
    "pos": { "x": number, "y": number, "z": number },
    "rot": { "x": number, "y": number, "z": number },
    "scale": { "x": number, "y": number, "z": number }
  }
}

## Behavior

- numeric inputs update preview immediately
- commit happens on blur or Enter
- values are sanitized (no NaN / Infinity)

## Determinism
- same input => same transform
- no floating drift (rounded precision)

## Invariants
- no direct snapshot mutation
- one commit per confirmed edit
- preview state is separate

## Forbidden
- partial transform corruption
- mixing degrees/radians inconsistently
