# Tier 7.5 — Multi-Select + Pivot & Bounding Box (UI)

## Purpose (LOCKED)
Enable multi-selection UX (selection set + bounding box + pivot) and
emit governed transform payloads that apply to multiple targets.

## Invariants
1. UI never mutates snapshots directly.
2. Multi-select transforms must execute through Phase T tool governance.
3. Draft-only + lock-required (Phase U).
4. Result is always a NEW child draft snapshot.
5. Selection/pivot is metadata in the payload, not authority.

## Selection Model
- selected_target_ids: [string, ...]
- selection_bbox: { min:{x,y,z}, max:{x,y,z} } (optional UI-provided)
- pivot_mode: "bbox_center" | "world_origin" | "custom"
- pivot: {x,y,z} (required if pivot_mode == "custom")

## Tool Payload Extension (Transform)
payload may include:
- selected_target_ids[]
- pivot_mode
- pivot
- selection_bbox (optional)
- drag_source: "gizmo"|"nudge" (optional)

## Validation
- selected_target_ids must be a non-empty list for multiselect execution
- pivot_mode must be valid
- if pivot_mode == "custom", pivot must exist and be numeric
- invalid inputs => 422

## Audit
action: "snapshot.transform"
extra:
- selected_target_ids_count
- pivot_mode
- drag_source
