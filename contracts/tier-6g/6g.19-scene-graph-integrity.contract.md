# Tier 6G.19 — Scene Graph Integrity

## Purpose (LOCKED)
Build correct parent-child hierarchy in viewer.

## Inputs

objects[] with:
- id
- parent_id (optional)

## Behavior

- attach child to parent group
- attach root objects to scene root

## Invariants

- no duplicate attachment
- no orphan nodes
- deterministic

## Forbidden

- flat scene structure
- ignoring parent_id
