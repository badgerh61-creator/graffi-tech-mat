# Tier 4.4 — Performance Metric Engine

## Purpose
Compute deterministic, snapshot-derived performance metrics from tuning state.

## Inputs
- snapshot_id
- snapshot.status
- tuning_state (engine, drivetrain, wheels, suspension, aero)
- vehicle_constants (mass_kg, drivetrain_layout, base_cd, frontal_area_m2) (optional)

## Outputs (PerformanceMetrics)
- power_hp
- torque_nm
- power_to_weight_hp_per_ton
- est_0_100_kph_seconds
- est_top_speed_kph
- handling_index
- braking_index
- notes[] (human-readable explanations)
- confidence 0.0–1.0

## Invariants
1. Metrics are pure and deterministic: same input -> same output
2. Metrics never mutate snapshot or DB
3. Missing inputs produce degraded confidence + notes (never crash)
4. Metrics must be safe for read-only access (viewer allowed)
5. Engine must be unit-stable (kph, kg, hp, Nm)

## API
GET /snapshots/{snapshot_id}/metrics/performance

### Preconditions
- Snapshot exists

### Success
200 + PerformanceMetrics JSON

### Failure
404 if snapshot not found
