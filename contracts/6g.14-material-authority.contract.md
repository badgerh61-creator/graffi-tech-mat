# Tier 6G.14 — Material Authority Layer

## Purpose (LOCKED)
Apply material overrides from snapshot state onto real mesh materials
in the viewer.

## Inputs

From snapshot → scene index:

objects[].material_state (optional)

Example:
{
  "material_state": {
    "paint": {
      "color": "#ff0000",
      "metalness": 0.8,
      "roughness": 0.2
    }
  }
}

## Behavior

1. Viewer MUST:
   - read material_state per object
   - traverse mesh hierarchy
   - apply material overrides

2. Supported parameters:
   - color (hex)
   - metalness (0–1)
   - roughness (0–1)

3. If no material_state:
   - keep original GLB material

## Determinism

- Same snapshot → same material output

## Invariants

- Read-only (no snapshot mutation)
- No backend writes
- No randomness

## Forbidden

- mutating original GLTF material reference
- modifying snapshot
