# Tier 7.23 — Shared PivotControls + UI Validation

## Purpose (LOCKED)
Unify pivot UI across transform panel and gizmo, and block invalid custom pivot
before tool execution.

## Validation Rules
If pivot_mode == "custom":
- pivot.x, pivot.y, pivot.z must be finite numbers (not NaN, not Infinity)

## Invariants
1. PivotControls is shared by TransformToolPanel and TransformGizmo.
2. Invalid pivot blocks UI execution with reason "invalid_pivot".
3. Backend remains authoritative, but UI avoids preventable 422s.
