# Tier 7.16 — Selection Event Unification (Typed-First)

## Purpose (LOCKED)
Make typed selection (Tier 7.13) the canonical source of selection events.
Legacy selectedId store remains a compatibility bridge only.

## Invariants
1. All new selection events must update typed selection store (primary/secondary/hovered).
2. Legacy selectionStore.js may be updated for compatibility, but must not be required.
3. Clearing selection clears BOTH typed and legacy stores.
4. Selection updates are deterministic and explicit.

## Forbidden
- Components using legacy selectedId as authoritative selection
- Tools guessing target ids
