# Tier 7.67 — Keyboard Shortcuts

## Purpose (LOCKED)
Provide deterministic keyboard shortcuts for common editor actions.

## Scope
- transform mode switching
- undo / redo
- duplicate
- selection helpers

## Input Model
Keyboard events are interpreted into:
{
  "action": "string",
  "context": "editor"
}

## Core Actions
- TRANSFORM_TRANSLATE (G)
- TRANSFORM_ROTATE (R)
- TRANSFORM_SCALE (S)
- UNDO (Ctrl+Z)
- REDO (Ctrl+Shift+Z)
- DUPLICATE (Ctrl+D)
- CLEAR_SELECTION (Esc)

## Behavior
- shortcuts only active when editor is focused
- disabled when typing in inputs
- actions routed through existing tool system

## Determinism
- same key => same action
- no timing-based behavior
- no hidden state

## Invariants
- no direct snapshot mutation
- one action per key event
- no duplicate event firing

## Forbidden
- conflicting bindings
- browser override hacks (except preventDefault when necessary)
