# Tier 5.1 — Testing Scenarios (Read-only)

## Purpose
Provide a read-only catalog of "testing scenarios" (track/city/highway presets)
used by Tier 5.2 and Tier 5.3.

Scenarios are metadata only:
- name
- category (track|city|highway)
- surface (asphalt|wet|gravel|mixed)
- weather preset (sunny|rain|fog|night)
- camera preset id (optional)
- lighting preset id (optional)

No physics. No simulation.

## Invariants
1) Read-only: no create/update/delete endpoints
2) Deterministic: catalog is stable across calls for same version
3) Safe access: viewer role allowed
4) No snapshot reads required

## API
GET /testing/scenarios
GET /testing/scenarios/{scenario_id}

### Success
200 + scenario(s)

### Fail
404 for unknown scenario_id
