# Tier 7.46 — Asset Import Slot (GLB Picker → Scene Object Ref)

## Purpose (LOCKED)
Allow adding real 3D assets (vehicle GLB) into the snapshot scene as references:
- user chooses an asset from a stable registry
- commit adds a scene object that references that asset
- viewer loads GLB at render time

## Asset Registry (read-only)
GET /assets/models -> { assets: [{id, name, url, kind, tags[]}] }

## Scene Object Storage (Authoritative)
snapshot.body_state.objects: list[SceneObject]

SceneObject:
{
  "id": "obj-uuid",
  "kind": "model_ref",
  "name": "string",
  "asset_id": "asset-...",
  "transform": { "pos":{x,y,z}, "rot":{x,y,z}, "scale":{x,y,z} },
  "layers": ["default"],
  "enabled": true,
  "version": 1
}

## Tools (Governed)
SCENE_ADD_MODEL_REF
payload:
{
  "asset_id": "asset-...",
  "name": "string?",
  "transform": optional
}

SCENE_REMOVE_OBJECT
payload:
{
  "object_id": "obj-..."
}

## Evaluate Rules
- asset_id must exist in registry
- new object id is generated deterministically by server (uuid ok)
- add allowed only in draft + lock owned (existing governance)

## Apply Rules
- mutate only snapshot.body_state.objects
- add/remove object entries deterministically
- no raw geometry stored

## Viewer
- for model_ref objects:
  resolve url from asset_id and load with GLTFLoader
  attach group under objectId root
- on failure: show placeholder mesh with objectId label

## Invariants
- no upload
- no backend geometry parsing required
- deterministic list ordering: objects sorted by id after apply
