# Tier 7.30 — Snapshot Diff Preview (UI-only)

## Purpose (LOCKED)
Show a deterministic, human-readable preview of changes between two snapshots.

## Inputs
- Snapshot A (base) + Snapshot B (target)
- Prefer B.parent_snapshot_id as base if present

## UI Behavior
- Select a snapshot node -> show diff vs its parent (or selected base)
- Diff is read-only, UI-only
- If base missing, show "No parent/base to diff"

## Output Format (example)
- body.panels: +2, -0, ~1
- body.nodes: +0, -1, ~3
- decor: ~2 keys changed
- tuning: no changes
- meta: status change DRAFT -> COMPLETED

## Determinism Rules
- JSON keys are compared in sorted order
- arrays of objects are matched by "id" when present
- otherwise fall back to index-based diff (stable)

## Invariants
- No backend writes
- No mutation of snapshots
- Must not rely on non-deterministic ordering
