# Tier 4.2 — Engineering Assistant (Tuning Context Binding)

## Purpose

Bind assistant to snapshot.tuning_state
Allow analysis and proposal generation.

No mutation allowed.

---

## Input Context

AssistantContext includes:

- snapshot_id
- tuning_state
- derived_metrics
- snapshot_status
- user_role
- draft_ownership_state

---

## Allowed Modes

- inquiry
- calculation
- proposal
- review

---

## Forbidden

- Direct snapshot mutation
- Tool registry invocation
- Draft creation
- Auto-apply proposal
- Flow transitions

---

## Output Structure

AssistantResponse:

{
  "analysis": {...},
  "issues": [...],
  "recommendations": [...],
  "proposals": [...],
  "confidence": 0.0-1.0
}

---

## Invariants

- Assistant cannot modify snapshot
- Assistant proposals must be structured
- Proposals must require explicit tool invocation later
- All assistant calls are audited
