# Tier 6G.15 — Decal Projection Engine

## Purpose (LOCKED)
Project decal textures onto mesh surfaces using snapshot decal_state.

## Inputs

objects[].decal_state

Example:
{
  "decal_state": [
    {
      "id": "logo",
      "texture_url": "/assets/logo.png",
      "position": { "x": 0, "y": 1, "z": 0 },
      "rotation": { "x": 0, "y": 0, "z": 0 },
      "scale": { "x": 1, "y": 1, "z": 1 }
    }
  ]
}

## Behavior

- load decal texture
- project using DecalGeometry
- attach to object group

## Invariants

- read-only snapshot
- deterministic placement
- decals independent meshes

## Forbidden

- modifying base mesh UVs
- mutating original materials
