# Tier 7.35 — Draft Workspace + Studio Modes (READ ↔ EDIT)

## Purpose (LOCKED)
Turn the Studio from a viewer shell into a real governed editor by introducing:
- READ mode (view-only)
- EDIT mode (draft workspace session)

EDIT mode is always backed by a draft snapshot the user owns (Phase U lock).

## Canonical Modes
- READ: no mutation routes, tools/gizmo disabled
- EDIT: tools/gizmo enabled ONLY if:
  - active snapshot is draft
  - user owns draft lock
  - station/mode/flow governance applies (Phase T)

## Invariants (NON-NEGOTIABLE)
1. No snapshot is mutated in place. All edits happen on a draft snapshot.
2. Enter Edit on a completed snapshot MUST create a child draft snapshot and acquire lock.
3. Enter Edit on an existing draft MUST acquire lock (or fail 403).
4. Complete Draft transitions draft -> completed (no geometry mutation implied here).
5. Discard Draft returns to parent snapshot and releases lock (best-effort).
6. All mode transitions emit audit events.
7. Frontend shows tool panels only in EDIT mode.

## API (Additive)
POST /snapshots/{snapshot_id}/start-edit
Response 200:
{ "mode": "edit", "draft_snapshot_id": int }

POST /snapshots/{draft_snapshot_id}/complete-draft
Response 200:
{ "mode": "read", "completed_snapshot_id": int }

POST /snapshots/{draft_snapshot_id}/discard-draft
Response 200:
{ "mode": "read", "parent_snapshot_id": int }

## Failure Modes
- 401 unauthenticated
- 403 lock required / not owner
- 404 snapshot not found
- 409 invalid status transition
- 422 invalid request shape

## Audit (Required)
- action: "studio.mode.start_edit" extra: { parent_snapshot_id?, draft_snapshot_id }
- action: "studio.mode.complete_draft" extra: { draft_snapshot_id, completed_snapshot_id }
- action: "studio.mode.discard_draft" extra: { draft_snapshot_id, parent_snapshot_id? }

## Forbidden
- any UI “editable flag” that bypasses kernel/lock truth
- completing or discarding snapshots without lock
- editing without owning a draft snapshot
