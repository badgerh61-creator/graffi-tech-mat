## 4. IMMUTABLE GUARANTEES (GLOBAL)

### 4.1 Deterministic State

- All geometry is regeneratable
- No derived meshes are authoritative
- Snapshots are immutable records

---

### 4.2 Immutable History

- No snapshot is ever mutated
- All changes create child snapshots
- Parent → child linkage proves causality

---

### 4.3 Capability-Gated Authority

- All actions require explicit capability
- Capabilities are server-derived
- UI cannot infer permissions

---

### 4.4 Zero UI Authority

UI may:
- Request
- Display
- Suggest

UI may NOT:
- Decide legality
- Enforce rules
- Mutate state

---

### 4.5 Audit Supremacy

Every significant action emits an audit event containing:

- actor_user_id
- phase
- station (if applicable)
- tool (if applicable)
- snapshot_id
- timestamp

Audit logs are the **source of truth**.
