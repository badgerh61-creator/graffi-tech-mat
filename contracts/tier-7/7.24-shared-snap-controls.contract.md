# Tier 7.24 — Shared SnapControls + Payload Parity

## Purpose (LOCKED)
Unify snapping UI and ensure transform payloads use one canonical snap shape.

## Canonical Snap Shapes
Translate payload includes:
snap: { enabled: boolean, step: number }

Rotate payload includes:
snap: { enabled: boolean, step_degrees: number }

Scale payload includes:
snap: { enabled: boolean, step_factor: number }

## Invariants
1. SnapControls is shared by TransformToolPanel and TransformGizmo.
2. Snap values are deterministic and explicit in payload.
3. UI blocks invalid snap steps (<=0 when enabled) before execution.
4. Backend remains authoritative.
