# Tier 7.18 — Multi-Select Click Modifiers (Shift/Ctrl)

## Purpose (LOCKED)
Enable deterministic multi-selection behavior via click modifiers:
- no modifier: replace selection with winner
- shift: toggle winner in selection
- ctrl: add winner to selection

## Invariants
1. Selection resolution is deterministic and centralized:
   - use backend POST /selection/resolve (Tier 7.6)
2. UI updates typed selection store only through canonical actions.
3. Primary selection must always be in the selection set when the set is non-empty.
4. Legacy selectedId is updated only to mirror typed primary (compat only).
5. Clicking empty space clears selection unless modifiers held.

## Forbidden
- Ad-hoc selection toggling in components
- Using legacy selectedId as authoritative
