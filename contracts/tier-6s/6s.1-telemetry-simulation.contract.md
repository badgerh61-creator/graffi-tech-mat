# Tier 6S.1 — Deterministic Telemetry Simulation (Artifacts Only)

## Purpose (LOCKED)
Generate time-series telemetry artifacts from (snapshot + scenario) without mutating snapshots.
Simulation is represented as a Job and produces an immutable Artifact.

## Invariants (NON-NEGOTIABLE)
1. No snapshot mutation (inputs are read-only).
2. Outputs are immutable artifacts.
3. Deterministic: same (snapshot_id, scenario, engine_version) -> same curves.
4. Audited: job created + artifact created.
5. Viewer-accessible for any user who can view the snapshot.

## Entities
### Simulation Job
- id: int
- snapshot_id: int
- scenario_json: string (json)
- engine_version: string ("pseudo-v1")
- status: queued|running|succeeded|failed
- artifact_id: int|null
- error: string|null

### Telemetry Artifact
- id: int
- snapshot_id: int
- scenario_hash: string
- engine_version: string
- timestep_s: number
- duration_s: number
- curves:
  - time_s: number[]
  - speed_mps: number[]
  - rpm: number[]
  - engine_temp_c: number[]
  - grip: number[]

## API (Additive)
### POST /simulation/jobs
Request:
{
  "snapshot_id": int,
  "scenario": {
    "duration_s": number (default 10),
    "timestep_s": number (default 0.1),
    "throttle": number 0..1 (default 0.6),
    "gear_ratio": number (default 10),
    "mass_kg": number (default 1200)
  },
  "engine_version": "pseudo-v1"
}

Response 200:
{
  "job_id": int,
  "status": "queued"|"running"|"succeeded"|"failed",
  "artifact_id": int|null
}

### GET /simulation/jobs/{job_id}
Response 200:
{
  "job_id": int,
  "snapshot_id": int,
  "status": "...",
  "artifact_id": int|null,
  "error": string|null
}

### GET /simulation/artifacts/{artifact_id}
Response 200:
{
  "artifact_id": int,
  "snapshot_id": int,
  "engine_version": string,
  "timestep_s": number,
  "duration_s": number,
  "curves": {...}
}

## Failure Modes
- 401 unauthenticated
- 403 unauthorized to view snapshot (if access checks exist)
- 404 snapshot/job/artifact not found
- 422 invalid scenario fields / unknown engine_version

## Forbidden
- Live driving loop
- Any writes to snapshot scene/transforms
- Non-deterministic randomization
