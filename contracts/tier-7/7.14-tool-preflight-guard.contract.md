# Tier 7.14 — Tool Preflight Guard (Selection + Block Reasons)

## Purpose (LOCKED)
Provide a single UI preflight guard that blocks tool execution when selection is missing
or when the UI is not eligible to execute (disabled state), before calling the backend.

## Inputs
- selection: SelectionState (typed, Tier 7.13)
- uiDisabled: boolean (e.g. not editable)
- activeSnapshotId?: number|null

## Outputs
PreflightResult:
- ok: true, target_id: string
OR
- ok: false, reason:
  - "no_selection"
  - "no_snapshot"
  - "ui_disabled"

## Invariants
1. Tools must not call executeTool() unless preflight.ok == true.
2. no_selection must be detected via resolvePrimaryTarget(selection).
3. Guard must be pure and deterministic.

## Forbidden
- Tools guessing a target_id
- Tools silently falling back to old selectedId
