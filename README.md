# Graffi-Tech-Mat — Full Production Project

This repository contains a production-ready backend and admin frontend.
- FastAPI backend with JWT auth
- Celery worker + Redis
- Postgres for production
- MinIO S3-compatible storage
- Alembic migrations
- React (Vite) admin frontend
- Docker and docker-compose (dev + prod)

See .env.template and .env.prod.template for configuration.
