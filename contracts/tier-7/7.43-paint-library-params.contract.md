# Tier 7.43 — Paint Library + Param Tweaks (Governed, Deterministic)

## Purpose (LOCKED)
Allow controlled paint/material tweaks on top of presets:
- color picker
- roughness / metalness sliders
- opacity slider
while keeping deterministic, clamped params and governed commits.

## Storage (Authoritative)
decor_state.material_overrides[target_id] = {
  "preset": "<preset_id>",
  "params": {
     "color": "#RRGGBB",
     "roughness": 0..1,
     "metalness": 0..1,
     "opacity": 0..1
  },
  "version": 1
}

## Tools (Governed)
1) MATERIAL_SET_PRESET (from 7.42) still valid
2) MATERIAL_UPDATE_PARAMS
payload:
{
  "target_id": "<target_id>",
  "patch": { "color"?, "roughness"?, "metalness"?, "opacity"? }
}

## Evaluate Rules
- target_id required
- patch must be object with allowed keys only
- color must match "#RRGGBB"
- numeric params must be finite and within [0..1] (or will be clamped in apply)
- update requires override exists; if none exists -> 409

## Apply Rules
- clamp numeric values to [0..1]
- normalize color to uppercase #RRGGBB
- mutate only decor_state.material_overrides

## Viewer
- effective material uses:
  preset base + overridden params
- deterministic precedence stays:
  mesh override > object override

## Invariants
- no snapshot mutation from UI
- no nondeterministic formatting
- one commit per action
