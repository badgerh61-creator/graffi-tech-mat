# Tier 6G.16 — Mesh Role Mapping

## Purpose (LOCKED)
Assign semantic roles to meshes so tools can target specific parts.

## Input

objects[].mesh_roles

Example:
{
  "mesh_roles": {
    "wheel_fl": "Wheel_FL",
    "wheel_fr": "Wheel_FR",
    "body": "CarBody",
    "glass": "Glass"
  }
}

## Behavior

Viewer MUST:
- traverse mesh hierarchy
- match mesh.name to role names
- build role → mesh map

## Invariants

- read-only
- deterministic
- no mesh mutation

## Forbidden

- renaming meshes
- guessing roles randomly
