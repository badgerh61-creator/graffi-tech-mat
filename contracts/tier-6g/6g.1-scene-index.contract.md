# Tier 6G.1 — Scene Index (Read-Only)

## Purpose (LOCKED)
Expose deterministic scene object metadata for a snapshot.

## Endpoint
GET /projects/{project_id}/snapshots/{snapshot_id}/scene

## Success 200
{
  "snapshot_id": int,
  "objects": [
    {
      "id": string,
      "kind": string,
      "name": string,
      "asset_ref": string|null,
      "transform": {
        "position": { "x": number, "y": number, "z": number },
        "rotation": { "x": number, "y": number, "z": number },
        "scale": { "x": number, "y": number, "z": number }
      }
    }
  ]
}

## Invariants
1. Read-only (no mutation)
2. Deterministic (same snapshot → same output)
3. Viewer-accessible (any user who can view snapshot can read scene)
4. Must degrade gracefully if missing scene data (defaults), never crash
