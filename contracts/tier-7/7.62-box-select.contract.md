# Tier 7.62 — Box Select / Marquee Selection

## Purpose (LOCKED)
Allow users to select multiple objects by dragging a rectangle in the viewport.

## Interaction Model
- mouse down + drag = selection rectangle
- mouse up = compute selected objects
- selection works in screen space

## Behavior
- objects intersecting rectangle are selected
- selection respects modifier keys:
  - no modifier → replace selection
  - shift/ctrl/cmd → additive toggle selection

## Selection Source
- selection operates on object ids only
- mesh hits map to parent object id
- decals are excluded in Tier 7.62

## Determinism
- same camera + same rectangle => same selectedIds
- selection order sorted by object id

## Invariants
- no snapshot mutation
- no backend calls
- selection state lives only in frontend

## Forbidden
- selecting mesh-level ids
- selecting invisible objects
- non-deterministic ordering
