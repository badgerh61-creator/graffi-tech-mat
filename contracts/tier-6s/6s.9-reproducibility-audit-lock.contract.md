# Tier 6S.9 — Reproducibility + Audit Lock (Trust Layer)

## Purpose (LOCKED)
Attach a reproducibility record to every run:
- snapshot_hash
- scenario_hash
- engine_version
- run_fingerprint
- verified_deterministic flag

## Invariants (NON-NEGOTIABLE)
1. No snapshot mutation. No artifact mutation.
2. Hashing is deterministic:
   stable_hash(json(sorted keys)).
3. run_fingerprint must be stable for same underlying record.
4. verified_deterministic only depends on:
   - engine_version in deterministic allowlist
   - presence of required hashes

## Entities

### Run Repro Record (fields on SimulationRun)
- snapshot_hash: string
- scenario_hash: string
- engine_version: string
- run_fingerprint: string
- verified_deterministic: bool

## API (Additive)

### GET /simulation/runs/{run_id}/repro
200:
{
  "run_id": int,
  "artifact_id": int,
  "snapshot_id": int,
  "scenario_id": int|null,
  "engine_version": str,
  "snapshot_hash": str,
  "scenario_hash": str,
  "run_fingerprint": str,
  "verified_deterministic": bool
}

## Forbidden
- changing artifacts to “fix” hashes
- non-deterministic fingerprint logic
