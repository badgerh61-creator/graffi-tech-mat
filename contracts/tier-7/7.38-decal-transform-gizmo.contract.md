# Tier 7.38 — Decal Transform Gizmo (Preview + Single Commit)

## Purpose (LOCKED)
Allow users to move/rotate/scale decals using a viewport gizmo:
- drag updates UI-only preview of decal transform
- on drag end, send one governed DECAL_UPDATE commit

## Inputs
- active decal selection: decal_id
- active snapshot: must be draft + lock owned (EDIT mode)

## Viewer Behavior
- Create a decal proxy object3D per active decal
- Attach TransformControls to the active decal proxy
- On objectChange while dragging -> update preview store (no backend)
- On dragging end -> clear preview and commit DECAL_UPDATE with final patch

## Tool Payload
DECAL_UPDATE:
{
  "decal_id": "dec-...",
  "patch": {
    "position": {x,y,z},
    "rotation_euler": {x,y,z},  # degrees
    "scale": {x,y,z}
  }
}

## Determinism
- degrees are rounded to fixed precision (e.g. 0.01)
- vectors rounded to fixed precision (e.g. 1e-4)
- stable axis/mode mapping (translate|rotate|scale)

## Invariants
- UI-only preview while dragging
- exactly one commit per drag release
- no edits allowed when NOT (draft+lock)
- no snapshot writes from client

## Forbidden
- multiple commits per drag
- preview leaking across snapshot navigation (Tier 7.31)
