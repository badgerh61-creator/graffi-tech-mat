# Tier 7.28 — Undo / Redo UI (Snapshot Navigation)

## Purpose (LOCKED)
Allow users to navigate snapshot lineage (undo/redo) in the editor UI.

## Behavior
- Undo moves from current snapshot -> parent snapshot (if exists)
- Redo moves from current snapshot -> next snapshot along the active branch (if exists)

## API (Read-only navigation)
POST /snapshots/{snapshot_id}/undo
POST /snapshots/{snapshot_id}/redo

Success 200:
{
  "from_snapshot_id": int,
  "to_snapshot_id": int,
  "status": "ok"
}

Errors:
- 404 if snapshot not found
- 409 if undo/redo not possible (no parent / no redo target)
- 403 if user lacks access

## Invariants
- No snapshot mutation
- Deterministic navigation (same snapshot state => same result)
- Viewer-accessible for snapshots user can view
