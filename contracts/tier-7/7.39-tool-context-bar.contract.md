# Tier 7.39 — Tool Context Bar (Studio Header)

## Purpose (LOCKED)
Add a persistent tool context bar that:
- displays selection target
- displays active tool mode (translate/rotate/scale)
- displays snap settings
- provides quick tool toggles
- explains why tools are disabled (from 7.36 reasons)

## Inputs
- activeSnapshot (id, status)
- selectionStore.selectedId
- lockStatus (owned/taken/missing/unknown)
- canEdit computed truth (draft + lock + role + station)
- whyBlocked reasons (deterministic list)

## UI Behavior
- Always visible (even in READ mode)
- If canEdit=false:
  - toggles disabled
  - show "Editing blocked" with reasons
- If canEdit=true:
  - toggles change gizmo mode store
  - snap toggle updates snap store

## Determinism
- snap store is canonical
- tool mode store is canonical
- no hidden local state that diverges from stores

## Invariants
- No backend calls
- No snapshot writes
- No selection mutation from bar
