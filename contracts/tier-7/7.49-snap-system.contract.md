# Tier 7.49 — Snap System

## Purpose (LOCKED)
Add deterministic transform precision controls for the editor:
- translation grid snap
- rotation angle snap
- scale step snap
- axis lock
- local/world orientation mode

## Inputs
- active gizmo mode: translate | rotate | scale
- selection target
- snap settings store
- axis lock store
- orientation mode store

## UI Behavior
- snap settings are shared by all transform entry points
- gizmo preview must respect snap exactly
- final governed commit must match preview values
- axis lock constrains motion to one axis when active
- orientation mode changes transform basis:
  - local
  - world

## Canonical Store Shape
{
  enabled: boolean,
  step: number,
  step_degrees: number,
  step_factor: number,
  axis_lock: "none" | "x" | "y" | "z",
  orientation: "local" | "world"
}

## Determinism
- same raw drag + same snap settings => same preview + same final payload
- snap values are clamped to safe finite minimums
- axis lock is single-source-of-truth

## Invariants
- no backend writes from snap changes
- no snapshot mutation from snap changes
- preview and commit must not diverge
- changing snap settings does not change selection

## Forbidden
- local component state that drifts from canonical store
- applying different snap logic in preview vs commit
