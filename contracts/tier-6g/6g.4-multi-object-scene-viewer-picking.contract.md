# Tier 6G.4 — Multi-Object Scene Viewer + Picking (Asset-backed)

## Purpose (LOCKED)
Render ALL scene objects from:
GET /projects/{project_id}/snapshots/{snapshot_id}/scene
and enable deterministic picking that resolves correct scene object + mesh.

## Inputs
sceneIndex.objects[] = { id, kind, asset_ref, transform }

## Asset Resolution
- asset_ref "asset:<id>" must be resolved via:
  GET /assets/<id>/url -> { url, type }
- only GLB is supported for rendering

## Viewer Behavior
1) For each object:
   - Create group named "obj:<objectId>"
   - Apply object.transform to that group
   - If asset_ref exists:
       resolve -> load GLB -> add gltf.scene under group
     Else:
       add placeholder mesh for visibility
2) Picking:
   - Raycast against all pickable meshes
   - Winner = nearest intersection
   - selectedId = "{object_id}::{mesh_name_or_uuid}"
   - object_id comes from mapping mesh -> objectId (not guessed)

## Determinism
- object group names are deterministic: obj:<objectId>
- mesh key = mesh.name if non-empty else mesh.uuid
- same click on same mesh -> same selectedId (within same load)

## Invariants
- read-only (no backend writes)
- no snapshot mutation
- no auto-selection
