# Phase 5.5 — Undo / Redo Command Graph

## Purpose
Navigate immutable snapshot history via command graph traversal.

---

## Definitions

- Snapshot graph is a DAG
- Each transform creates one child snapshot
- parent_snapshot_id defines lineage

---

## Undo Rules

- Undo moves to parent_snapshot_id
- If no parent exists, undo is blocked

---

## Redo Rules

- Redo moves to selected child snapshot
- If no child exists, redo is blocked

---

## API Endpoints

POST /projects/{project_id}/snapshots/{snapshot_id}/undo
POST /projects/{project_id}/snapshots/{snapshot_id}/redo

---

## Success Response

```json
{
  "active_snapshot_id": "uuid",
  "status": "draft | completed"
}
```

---

## Failure Modes

| Condition | HTTP |
|---------|------|
| No parent | 409 |
| No child | 409 |
| Snapshot mismatch | 404 |
| Permission denied | 403 |

---

## Forbidden

- Geometry mutation
- Snapshot deletion
- Cross-branch traversal
