# Tier 7.55 — Paint Library Expansion

## Purpose (LOCKED)
Expand the material system into a real paint/finish library with:
- categorized finish presets
- saved swatches
- slot-aware preset apply
- deterministic material parameter defaults

## Authoritative Storage

### A) Material override storage (existing)
decor_state.material_overrides = {
  "<target_or_slot_key>": {
    "preset": "<preset_id>",
    "params": {
      "color": "#RRGGBB"?,
      "roughness": 0..1?,
      "metalness": 0..1?,
      "opacity": 0..1?
    },
    "version": 1
  }
}

### B) Paint swatches (new)
decor_state.paint_swatches : list[PaintSwatch]

PaintSwatch:
{
  "id": "sw-...",
  "name": "string",
  "color": "#RRGGBB",
  "finish": "gloss" | "matte" | "satin" | "metallic" | "chrome_like",
  "version": 1
}

## Read-only Registry
GET /materials/paint-library -> {
  "presets": [
    { "id", "name", "finish", "color", "roughness", "metalness", "opacity" }
  ]
}

## Tools (Governed)
PAINT_APPLY_LIBRARY_PRESET
payload:
{
  "target_id": "<object_id>" | "<object_id>::<mesh_path>" | "<object_id>::<mesh_path>::slot:<slot_name>",
  "preset": "<preset_id>"
}

PAINT_SAVE_SWATCH
payload:
{
  "name": "string",
  "color": "#RRGGBB",
  "finish": "gloss" | "matte" | "satin" | "metallic" | "chrome_like"
}

PAINT_DELETE_SWATCH
payload:
{
  "swatch_id": "sw-..."
}

PAINT_APPLY_SWATCH
payload:
{
  "target_id": "<target_key>",
  "swatch_id": "sw-..."
}

## Apply Rules
- library preset apply updates material_overrides[target_id]
- swatch save/delete mutates only decor_state.paint_swatches
- swatch apply updates material_overrides[target_id].params using swatch data

## Determinism
- preset ids are stable
- finish mapping to material params is stable
- swatches list sorted by id after apply
- same swatch + same target => same params

## Invariants
- no backend writes during browsing
- one governed commit per action
- no geometry mutation
- slot-aware targeting remains valid
