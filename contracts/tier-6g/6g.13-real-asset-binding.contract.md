# Tier 6G.13 — Real Asset Binding (Vehicle Loading)

## Purpose (LOCKED)
Bind real Asset records (GLB) into the scene index so the viewer renders
actual models instead of placeholders.

## Inputs

GET /snapshots/{snapshot_id}/scene

Returns:
{
  "snapshot_id": int,
  "objects": [
    {
      "id": string,
      "kind": string,
      "asset_ref": string|null,
      "transform": {
        "position": { "x": number, "y": number, "z": number },
        "rotation": { "x": number, "y": number, "z": number },
        "scale": { "x": number, "y": number, "z": number }
      }
    }
  ]
}

## Asset Resolution

asset_ref MUST support:
- "asset:<id>" → resolved via /assets/{id}/url
- null → placeholder

## Behavior

1. Scene index MUST include asset_ref when asset_id exists.
2. asset_ref MUST be deterministic for a snapshot.
3. Viewer MUST:
   - resolve asset_ref → API URL
   - fetch signed URL
   - load GLB via GLTFLoader
   - fallback to placeholder if load fails

## Determinism

- Same snapshot → same asset_ref
- No randomness
- No implicit reassignment

## Invariants

- Read-only
- No snapshot mutation
- No DB writes

## Forbidden

- Direct S3 URLs in scene index
- Random asset assignment
- Missing transform block
