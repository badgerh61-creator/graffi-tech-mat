# Phase 5.2 — Selection & Target Resolution

## Purpose
Define how editor selections resolve into authoritative transform targets.

---

## Definitions

- Selection: UI-level identifier chosen by user
- Target: Snapshot-resolved entity eligible for transform
- Resolution: Mapping selection → target

---

## Selection Types

- node (scene graph node)
- panel (body panel)
- curve (parametric curve)
- reference_plane

---

## Rules

- Selection never mutates state
- Resolution is deterministic
- Resolution is snapshot-scoped
- Invalid selections are rejected
- Completed snapshots cannot resolve editable targets

---

## API Endpoint

POST /projects/{project_id}/snapshots/{snapshot_id}/resolve-target

---

## Request Body

```json
{
  "selection_type": "node | panel | curve | reference_plane",
  "selection_id": "string"
}
```

---

## Preconditions

- User authenticated
- Snapshot exists
- Snapshot.status == "draft"
- Selection exists in snapshot scene graph

---

## Success Response

```json
{
  "target_id": "string",
  "target_type": "node | panel | curve | reference_plane",
  "editable": true
}
```

---

## Failure Modes

| Condition                    | HTTP |
|-----------------------------|------|
| Snapshot not found          | 404  |
| Snapshot not draft          | 409  |
| Selection not found         | 404  |
| Selection not editable     | 422  |
| Permission denied           | 403  |

---

## Forbidden

- Resolving targets on completed snapshots
- Implicit target inference
- Geometry mutation during resolution
