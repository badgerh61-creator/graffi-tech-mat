# Tier 6S.2 — Physics Plug-in Slot (Engine Abstraction)

## Purpose (LOCKED)
Decouple simulation execution from the API layer via an engine registry.

Allows swapping engines (pseudo baseline -> real physics later) without changing:
- API shape
- artifact schema
- governance rules

## Invariants
1. Engine selected by `engine_version` string.
2. Unknown engine_version -> 422.
3. Engine output shape is canonical:
   {
     "timestep_s": float,
     "duration_s": float,
     "curves": {...}
   }
4. Engines do NOT write DB.
5. No snapshot mutation.
6. No API changes.

## Forbidden
- Engine performing DB writes
- Engine altering artifact schema
- Engine mutating snapshots
