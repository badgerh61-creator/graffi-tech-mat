# Tier 7.40 — View Modes (Viewer-Only)

## Purpose (LOCKED)
Add deterministic viewport "view modes" to improve authoring and debugging:
- Studio (default): normal shaded materials + lights
- Solid: flat shaded, no textures
- Clay: neutral clay material (good for form)
- Wireframe: wireframe overlay or full wireframe

## Inputs
- viewMode store (UI-only)
- current scene objects + decals

## Viewer Behavior
- Must not mutate snapshot
- Must not perform backend writes
- Must not create non-deterministic ordering (stable per object id / mesh path)

## Mode Definitions
1) studio:
   - use original mesh materials
2) solid:
   - override all mesh materials with MeshStandardMaterial (no map)
3) clay:
   - override all mesh materials with MeshStandardMaterial (neutral clay color)
4) wireframe:
   - set material.wireframe=true OR override with wireframe-only material

## Restore Rule
When switching away from override modes, original materials must be restored.

## Invariants
- View mode affects rendering only
- View mode must be reversible without leaking materials
- View mode must work with decals (decals still render)
