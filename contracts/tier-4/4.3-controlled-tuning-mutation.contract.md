# Tier 4.3 — Controlled Tuning Mutation

## Purpose

Enable governed tuning mutations through registered Studio tools.

---

## Preconditions

- Snapshot.status == "draft"
- User holds draft ownership lock
- Tool registered in Phase T registry
- Flow graph allows mutation from current station
- Capability allows tuning mutation

---

## Behavior

- Clone parent draft snapshot
- Apply deterministic mutation
- Return new draft snapshot
- Append to undo graph
- Emit audit event

---

## Allowed Tools (initial)

- UPDATE_ENGINE_CONFIG
- UPDATE_SUSPENSION_CONFIG
- UPDATE_WHEEL_SETUP

---

## Forbidden

- Direct snapshot mutation
- Partial snapshot overwrite
- Auto-apply from assistant
- Mutation on completed snapshot

---

## Audit Event

action: "snapshot.tuning_updated"
extra:
    parent_snapshot_id
    tool_name
    mutation_payload_hash
