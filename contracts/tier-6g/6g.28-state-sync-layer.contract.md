# Tier 6G.28 — State Sync Layer

## Purpose (LOCKED)
Ensure viewer, UI, and backend snapshot are always synchronized.

## Source of Truth
Backend snapshot is authoritative.

## Behavior

1. After ANY mutation:
   → fetch latest snapshot
   → update central store
   → viewer re-renders

2. UI panels read from same state as viewer

3. No stale state allowed

## Determinism
Same snapshot → same UI + same viewer

## Invariants
- No partial updates
- No dual sources of truth
- No silent desync

## Forbidden
- optimistic viewer-only updates
- local mutation hacks
- stale snapshot usage
