# Tier 7.26 — True Drag Handles (2D Drag Pad → Governed Commits)

## Purpose (LOCKED)
Replace button nudges with real pointer drag handling that emits:
- TRANSLATE deltas
- ROTATE degrees
- SCALE factors
as governed tool commits.

## Invariants (NON-NEGOTIABLE)
1. Dragging is UI-only preview until pointer release.
2. On pointer release, a single governed tool commit occurs.
3. No snapshot mutation on the client.
4. Deterministic mapping: same drag pixels => same output, given same settings.
5. Selection is the only source of target_id.

## Drag Pad Behavior
- pointerdown starts a drag session
- pointermove updates local preview value
- pointerup commits payload via onCommit(payload)
- escape cancels drag (no commit)

## Mapping (deterministic)
Translate:
- deltaAxis = pixels * translateScale
Rotate:
- degrees = pixels * rotateScaleDegreesPerPixel
Scale:
- factor = 1 + pixels * scaleScalePerPixel
Clamp scale factor to [0.01, 100]

## Snap
If snap enabled:
- apply snap AFTER mapping and BEFORE commit using existing snap helpers.

## Forbidden
- multiple commits per drag
- committing when disabled
