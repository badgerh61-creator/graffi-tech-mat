# Phase 5.1 — Creation Primitives (Transform / Move / Scale)

## Purpose
Define safe, numeric geometry transforms applied to draft snapshots.

---

## Supported Operations

- translate (x, y, z)
- rotate (pitch, yaw, roll)
- scale (uniform only)

---

## Rules

- Only draft snapshots may be mutated
- Completed snapshots are immutable
- Operations are numeric and explicit
- Every operation produces a new scene state hash
- Operations are append-only (no destructive overwrite)

---

## API Endpoint

POST /projects/{project_id}/snapshots/{snapshot_id}/transform

---

## Request Body

```json
{
  "operation": "translate | rotate | scale",
  "target_id": "string",
  "params": {
    "x": 0,
    "y": 0,
    "z": 0
  }
}
```

---

## Preconditions

- User authenticated
- User has editor permission
- Snapshot exists
- Snapshot.status == "draft"
- Target exists in scene graph

---

## Success Response

```json
{
  "status": "applied",
  "snapshot_id": "uuid",
  "new_scene_state_hash": "string"
}
```

---

## Failure Modes

| Condition                    | HTTP |
|-----------------------------|------|
| Snapshot not found          | 404  |
| Snapshot not draft          | 409  |
| Permission denied           | 403  |
| Invalid transform           | 422  |

---

## Audit

Every transform MUST emit:

- actor_user_id
- project_id
- snapshot_id
- operation
- target_id
- params
- timestamp

---

## Forbidden

- Transforming completed snapshots
- Freeform sculpting
- Silent state mutation
- Implicit transforms
