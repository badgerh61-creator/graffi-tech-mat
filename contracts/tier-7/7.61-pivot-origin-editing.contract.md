# Tier 7.61 — Pivot / Origin Editing

## Purpose (LOCKED)
Allow users to edit object pivot/origin behavior in a deterministic, governed way
for more precise transforms and assembly editing.

## Authoritative Storage
snapshot.body_state.objects : list[SceneObject]

Extended SceneObject fields:
{
  "id": "obj-...",
  ...
  "transform": {
    "pos": { "x": number, "y": number, "z": number },
    "rot": { "x": number, "y": number, "z": number },
    "scale": { "x": number, "y": number, "z": number }
  },
  "pivot": {
    "x": number,
    "y": number,
    "z": number
  } | null,
  "version": 1
}

## Meaning
- pivot is an object-local offset used as the transform origin
- null means default/original object origin
- Tier 7.61 does not rebake mesh vertices
- viewer applies pivot by transform grouping only

## Tools (Governed)
SCENE_SET_OBJECT_PIVOT
payload:
{
  "object_id": "obj-...",
  "pivot": { "x": number, "y": number, "z": number }
}

SCENE_RESET_OBJECT_PIVOT
payload:
{
  "object_id": "obj-..."
}

SCENE_SET_OBJECT_PIVOT_PRESET
payload:
{
  "object_id": "obj-...",
  "preset": "center" | "bounds_bottom_center"
}

## Preset Rules
- center = object bounds center
- bounds_bottom_center = x/z center + min y
- preset computation uses authoritative visible object bounds in viewer space
- preset result is committed as explicit numeric pivot

## UI Scope
Tier 7.61 supports:
- enable pivot editing mode
- set numeric pivot
- apply preset pivot
- reset pivot
- temporary pivot preview before commit

Tier 7.61 does NOT yet require:
- per-vertex pivot picking
- shared multi-object pivot editing
- custom gizmo handle for pivot dragging

## Determinism
- same object + same preset + same bounds => same pivot
- same numeric input => same stored pivot
- reset always returns pivot to null

## Invariants
- no geometry mutation
- one governed commit per pivot action
- no snapshot mutation from preview only
- transform editing remains compatible with existing gizmo rules

## Forbidden
- rebaking model mesh vertices
- mutating source asset files
- storing NaN/Infinity pivot values
