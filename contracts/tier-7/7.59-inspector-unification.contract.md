# Tier 7.59 — Inspector Unification

## Purpose (LOCKED)
Unify object/material/decal/design panels into one professional inspector
driven by the current selection and editor state.

## Inspector Sections
Tier 7.59 must support these sections:
- Summary
- Transform
- Materials
- Paint
- Decals
- Asset Info
- Variants
- Constraints

## Inputs
- active snapshot
- current selection
- active decal selection
- lock/edit state
- constraint violations
- discovered material slots

## Behavior
- inspector is always visible
- section visibility is deterministic based on current context
- no section mutates snapshot directly; all edits still go through governed tools
- selection change updates inspector content

## Summary Section
Must show:
- target id
- selection kind
- snapshot id/status
- edit enabled / blocked state

## Section Visibility Rules
- Transform: visible when geometry selection exists
- Materials/Paint: visible when geometry or slot target exists
- Decals: visible when decal exists or placement tool active
- Asset Info: visible for scene object selection
- Variants: always allowed
- Constraints: visible when violations exist or selection has related target

## Determinism
- same state => same visible sections and order
- no hidden local state divergence

## Invariants
- no backend writes
- no snapshot mutation from layout only
- existing panel logic remains canonical; inspector composes it
