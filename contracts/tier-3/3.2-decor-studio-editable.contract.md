# Tier 3.2 — Decor Studio (Editable, Capability-Gated)

## Purpose
Enable controlled decor editing under studio kernel authority.

---

## Preconditions

- Active snapshot exists
- Active snapshot.status == "draft"
- User holds required capability
- User is in Decor Station

---

## Capabilities

- canEditExteriorDecor
- canEditInteriorDecor

---

## Allowed Operations

- decor.apply_material
- decor.replace_preset
- decor.adjust_parameter

---

## Execution Rules

- Each operation creates a new draft snapshot
- Parent snapshot is never mutated
- New snapshot must reference parent_snapshot_id
- Operation is recorded as a command

---

## Forbidden

- Editing completed snapshots
- UI-side mutation
- Batch mutation
- Implicit saves
