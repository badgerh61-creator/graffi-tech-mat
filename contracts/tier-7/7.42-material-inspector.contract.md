# Tier 7.42 — Material Inspector (Read + Governed Edit)

## Purpose (LOCKED)
Introduce a deterministic material inspector that can:
- list materials assigned to a selected target (object or mesh)
- assign a material preset to a target via governed commit

## Storage (Authoritative)
snapshot.decor_state.material_overrides : dict

Canonical:
decor_state.material_overrides = {
  "<target_id>": {
     "preset": "paint_gloss_red" | "matte_black" | "chrome" | ...,
     "params": { optional future fields },
     "version": 1
  }
}

## Targeting
target_id is selectionStore.selectedId:
- objectId
- or objectId::mesh_path

## Tools (Governed)
MATERIAL_SET_PRESET
payload:
{
  "target_id": "<target_id>",
  "preset": "<preset_id>"
}

MATERIAL_CLEAR_OVERRIDE
payload:
{
  "target_id": "<target_id>"
}

## Evaluate Rules
- target_id required and must be string
- preset required for set
- preset must be in allowed preset registry (server-side list)
- clear is allowed even if no override exists (no-op)

## Apply Rules
- Mutate only decor_state.material_overrides
- Must be reversible (clear)
- No geometry mutation

## Viewer
- If override exists for a mesh/object target_id:
  apply that preset material in viewer render (view-mode studio only)
- Deterministic precedence:
  mesh override wins over object override (if both exist)

## Invariants
- No backend writes during preview
- One commit per action
- Requires EDIT truth (draft + lock owned) to enable edits
