# Tier 7.60 — Multi-Select

## Purpose (LOCKED)
Allow deterministic multi-object selection and bulk object actions.

## Selection Model
Tier 7.60 adds a canonical multi-selection store:
{
  "primaryId": "obj-..." | null,
  "selectedIds": ["obj-...", ...]
}

## Rules
- selectedIds contains unique object ids only
- primaryId must be null or a member of selectedIds
- selection order is deterministic and stable
- additive selection is supported
- toggle selection is supported
- clear selection is supported

## Scope
Tier 7.60 supports multi-select for:
- object rows in outliner
- object picks in viewport
- bulk visibility toggles
- bulk layer assignment

Tier 7.60 does NOT yet require:
- box select
- multi-transform gizmo
- per-mesh multi-select

## Tools (Governed)
Bulk actions use existing tools per object or dedicated bulk tools.

Tier 7.60 canonical bulk tools:
SCENE_BULK_SET_ENABLED
payload:
{
  "object_ids": ["obj-..."],
  "enabled": true|false
}

SCENE_BULK_SET_LAYERS
payload:
{
  "object_ids": ["obj-..."],
  "layers": ["default", ...]
}

## Apply Rules
- bulk tools mutate only body_state.objects[*].enabled or .layers
- object_ids not found are ignored safely
- ordering of object_ids in payload must not affect result

## Determinism
- same selected set + same action => same result
- selectedIds stored sorted by insertion-preserving uniqueness
- bulk mutation result independent of request ordering

## Invariants
- no backend writes from selection changes
- one governed commit per bulk action
- selection state survives panel rerenders
- single-select flows still work through primaryId

## Forbidden
- duplicate ids in selectedIds
- primaryId outside selectedIds
- accidental mesh/decal ids in object multi-select
