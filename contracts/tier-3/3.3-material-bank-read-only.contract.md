# Tier 3.3 — Material Bank (Read-Only)

## Purpose
Expose available materials for inspection without mutation.

---

## Material Record Fields

- id
- name
- category (fabric | metal | paint | leather | glass)
- pbr_properties:
    - baseColor
    - roughness
    - metalness
    - normalMap
    - emissive
- version
- created_at
- created_by
- tags[]

---

## Behavior

- GET /materials returns paginated list
- No mutation endpoints
- No implicit preview application
- No snapshot mutation
- No draft creation

---

## Forbidden

- Direct application
- Editing
- Deleting
- Inline preview mutation
