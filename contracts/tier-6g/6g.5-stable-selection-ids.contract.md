# Tier 6G.5 — Stable + Human-Readable Selection IDs

## Purpose (LOCKED)
Make selection target IDs stable across viewer reloads and GLB re-exports by using
a deterministic mesh_path instead of UUIDs.

## Canonical Target ID Format (LOCKED)
selectedId = "{object_id}::{mesh_path}"

mesh_path:
- "/"-joined list of node names from object group boundary to mesh
- if node.name missing/empty: use deterministic fallback "unnamed-{indexWithinParent}"

Examples:
- vehicle-1::CarRoot/Body/Door_L
- vehicle-1::CarRoot/unnamed-3/unnamed-0

## Determinism Rules
- Same GLB hierarchy => same mesh_path
- Empty names => unnamed indices determined by parent.children order

## Invariants
- Read-only (no backend writes)
- Viewer selection uses canonical format
- No snapshot mutation

## Forbidden
- using mesh.uuid in selectedId
