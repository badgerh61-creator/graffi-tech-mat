# Tier 7.41 — Selection Filters + Select-through Rules

## Purpose (LOCKED)
Add deterministic selection filtering and picking priority rules so clicks
select the intended target (object/mesh/decal) and never drift across modes.

## Selection Filter Modes
selection.filter:
- all
- objects
- meshes
- decals

## Picking Targets (canonical)
- object pick id: "obj:<objectId>"
- mesh pick id:   "mesh:<objectId>::<mesh_path>"
- decal pick id:  "decal:<decalId>"

## Priority Rules (deterministic)
When filter == all:
1) decal
2) mesh
3) object

When filter == decals:
- only decal selectable

When filter == meshes:
- only mesh selectable (fallback none)

When filter == objects:
- only object selectable (fallback none)

## UI Behavior
- Filter is shown in ToolContextBar
- Changing filter does NOT change current selection immediately
- Clicking selects according to filter rules
- Selecting a decal sets activeDecalId and clears geometry selection (optional but deterministic)

## Invariants
- No backend writes
- Deterministic selection resolution from hit list
- Must not depend on hit order from renderer (sort by stable key)
