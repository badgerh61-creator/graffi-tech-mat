# Tier 7.15 — Gizmo Preflight + Typed Selection Binding

## Purpose (LOCKED)
Ensure gizmo commits use the same preflight gating as tools (Tier 7.14) and
bind target id from typed selection primary (Tier 7.13).

## Invariants
1. Gizmo must not execute if:
   - no snapshot ("no_snapshot")
   - UI disabled ("ui_disabled")
   - no selection primary ("no_selection")
2. Gizmo must not guess a target id.
3. Gizmo execution must go through Tool Execution Adapter (Tier 7.12) in proposals mode.
4. Errors must be normalized and shown consistently.

## Forbidden
- hardcoded target ids
- bypassing preflight guard
- direct fetch() calls in gizmo controller
