# Tier 7.76 — Gizmo Attach

## Purpose (LOCKED)
Attach transform gizmo to selected object.

## Behavior

When selection changes:
- find object group
- attach transform controls
- enable move/rotate/scale

On transform:
- update snapshot transform
- re-render viewer

## Invariants

- only one gizmo active
- gizmo follows selection
- transform deterministic

## Forbidden

- multiple gizmos
- detached transform
- viewer-only transforms (must update snapshot)
