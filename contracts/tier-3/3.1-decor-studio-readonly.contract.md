# Tier 3.1 — Decor Studio (Read-Only)

## Purpose
Provide a read-only view of vehicle decor configurations.

---

## Scope

The Decor Studio MAY:
- Display decor categories
- Show applied materials
- Show decor metadata
- Show source presets
- Show culture pack references

The Decor Studio MAY NOT:
- Modify decor
- Reorder layers
- Toggle visibility
- Apply presets
- Suggest changes

---

## Decor Domains

- exterior.paint
- exterior.decals
- exterior.materials
- interior.seats
- interior.dashboard
- interior.floor
- interior.lighting

---

## Data Source

All data MUST come from:
- active snapshot metadata
- decor registry

No UI-side derivation allowed.

---

## Display Requirements

Each decor item must include:
- id
- domain
- name
- material / preset reference
- source (manual / culture-pack)

---

## Forbidden

- Preview mutations
- Hover-based affordances implying edit
- Client-side decor logic
