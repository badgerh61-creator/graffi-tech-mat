# Tier 6S.8 — Endurance / Stress Mode (Artifact-only)

## Purpose (LOCKED)
Support long-duration simulation runs that produce:
- thermal saturation behavior
- degradation curves over time (grip + power fade)

## Invariants (NON-NEGOTIABLE)
1. No snapshot mutation.
2. Artifact immutable.
3. Deterministic: same inputs => same curves.
4. Bounded outputs:
   - grip in [0.2, 1.0]
   - engine_temp_c in [0, 2000] (hard guard)
   - arrays length = floor(duration/timestep)+1

## Scenario Extensions (Additive)
Scenario may include:
- mode: "default" | "endurance" (default "default")
- thermal_ceiling_c: number (default 130)
- degradation_rate: number (default 0.0008 per second)

## Engine
Add engine_version:
- "pseudo-endurance-v1"

## Forbidden
- realtime loop
- snapshot writes
- non-deterministic randomness
