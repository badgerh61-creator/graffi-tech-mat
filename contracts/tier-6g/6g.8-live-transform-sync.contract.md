# Tier 6G.8 — Live Transform Sync After Snapshot Change

## Purpose (LOCKED)
Ensure the real viewer stays visually consistent with the active snapshot after
governed apply creates a new snapshot.

This tier prevents stale transforms, ghost meshes, and selection drift by
rebinding the viewer to the latest scene index whenever activeSnapshot changes.

## Inputs
- activeSnapshot.id (frontend state)
- GET /snapshots/{snapshot_id}/scene (Tier 6G.1)
  - objects[]: { id, kind, asset_ref, transform }

## Behavior (Canonical)
1) When activeSnapshot.id changes:
   - fetch scene index for that snapshot id
   - replace viewer scene content (dispose previous meshes/materials)
   - re-apply transforms from the new scene index to each object group

2) Selection validity:
   - if selectedId exists and its object_id is not present in new objects[], clear selection
   - otherwise keep selection as-is (no auto-select)

3) Determinism:
   - same snapshot id + same scene index => same viewer output
   - no random camera changes required in this tier (camera framing handled in 6G.7)

## Invariants
- Read-only: no backend writes
- No snapshot mutation
- No implicit tool execution
- Must not leak WebGL resources (dispose on rebind)

## Forbidden
- keeping stale mesh instances after snapshot switch
- silently selecting a new object after snapshot switch
