# Tier 6G.27 — Scene Serialization

## Purpose (LOCKED)
Make snapshot the single source of truth for the entire scene.

## Source of Truth
Backend snapshot JSON

## Behavior

1. Viewer MUST render ONLY from snapshot data
2. Scene MUST be reconstructable from snapshot alone
3. No hidden viewer-side state allowed

## Object Shape

Each object MUST include:
- id
- asset_ref
- transform
  - position {x,y,z}
  - rotation {x,y,z}
  - scale {x,y,z}
- material_overrides
- decals

## Determinism
Same snapshot → identical scene (no drift)

## Invariants
- No implicit defaults changing behavior
- No mutation outside snapshot
- No missing fields

## Forbidden
- storing transforms in Three.js only
- incremental transform hacks (+=)
- viewer becoming source of truth
