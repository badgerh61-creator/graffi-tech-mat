# Tier 7.69 — View Modes

## Purpose (LOCKED)
Provide deterministic visual rendering modes for inspection and debugging.

## Modes
- default
- wireframe
- xray
- bounds

## Behavior

### Wireframe
- render meshes with wireframe material
- preserves original color where possible

### X-Ray
- reduce opacity
- disable depth write
- allow seeing through geometry

### Bounds
- render bounding boxes per object
- does not replace mesh rendering

## Mode Rules
- only one primary mode active at a time
- bounds can be toggled independently

## Determinism
- same mode => same rendering output
- no random shader variation

## Invariants
- no snapshot writes
- no geometry mutation
- no material mutation persistence

## Forbidden
- modifying original material definitions permanently
- mixing incompatible modes
