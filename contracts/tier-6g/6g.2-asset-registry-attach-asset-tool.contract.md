# Tier 6G.2 — Attach Asset Tool (Governed) using existing Asset Registry

## Purpose (LOCKED)
Attach an existing registered Asset (S3-backed) to a draft snapshot scene object,
so 6G.1 Scene Index returns real asset references.

## Existing Asset Registry (already present)
- GET /assets
- GET /assets/{asset_id}/url (presigned)

## Attach Tool Endpoint (NEW)
POST /projects/{project_id}/snapshots/{snapshot_id}/tools/attach-asset

Request:
{
  "object_id": "vehicle-1",
  "asset_id": 123,
  "kind": "vehicle" (optional),
  "name": "Supra" (optional)
}

Response 200:
{
  "snapshot_id": int,
  "object_id": string,
  "asset_ref": "asset:123"
}

## Scene Index Effect (6G.1)
GET /projects/{project_id}/snapshots/{snapshot_id}/scene
must include an object entry with:
- id == object_id
- asset_ref == "asset:{asset_id}"

## Invariants
- Draft-only (409 if not draft)
- Must respect ownership/lock rules
- Read-only except the explicit draft mutation here
- Deterministic scene objects ordering by id
- No cross-user bypass

## Notes
asset_ref is a stable pointer. Viewer resolves it via:
GET /assets/{asset_id}/url
