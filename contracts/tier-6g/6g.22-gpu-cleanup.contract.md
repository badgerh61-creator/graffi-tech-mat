# Tier 6G.22 — GPU Resource Cleanup

## Purpose (LOCKED)
Ensure all GPU resources are disposed when no longer needed.

## Resources

- geometries
- materials
- textures

## Behavior

- on scene rebuild → dispose everything
- on material replace → dispose old materials
- on decal replace → dispose decal resources

## Invariants

- no memory growth for repeated actions
- no orphan GPU objects

## Forbidden

- leaving textures alive
- keeping old materials
- reusing disposed resources
