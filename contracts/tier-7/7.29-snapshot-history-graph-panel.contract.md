# Tier 7.29 — Snapshot History Graph Panel (Read-only)

## Purpose (LOCKED)
Expose a visual snapshot lineage graph so users can:
- see parent chain
- see branches (children)
- jump to any snapshot id deterministically

## API (Preferred)
GET /snapshots/{snapshot_id}/history
200:
{
  "snapshot_id": int,
  "has_parent_links": bool,
  "nodes": [
    { "id": int, "parent_snapshot_id": int|null, "children_ids": [int,...] }
  ]
}

## Ordering Rules (Deterministic)
- nodes[] returned as: current -> parent -> ... -> root
- children_ids sorted ascending

## Fallback
If endpoint missing/unavailable:
- UI shows local historyStore.stack (linear)

## Invariants
- Read-only: no DB writes
- Viewer-accessible for snapshots user can view
- Deterministic output for same DB state

## Forbidden
- mutation
- non-deterministic ordering
