# Tier 7.10 — Viewport Picking Stub (Click-to-Select)

## Purpose (LOCKED)
Provide a safe, deterministic, engine-independent picking surface that drives selection.

## Invariants
1. Picking is UI-only (no backend writes).
2. Picking sets selectionStore.selectedId explicitly.
3. Picking never implies authority (does not bypass locks/modes/flows).
4. Picking must be deterministic:
   - click target id comes from explicit DOM data attribute (data-target-id)
5. If target id missing, click clears selection (allowed).

## Forbidden
- Any raycasting / engine calls in this tier
- Any snapshot mutation
