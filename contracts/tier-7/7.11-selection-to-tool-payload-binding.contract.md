# Tier 7.11 — Selection → Tool Payload Binding

## Purpose (LOCKED)
Bind viewport selection (selectedId) into transform tool payload construction.

## Invariants
1. Transform UI must NOT require manual target_id entry.
2. target_id MUST come from selectionStore.selectedId.
3. If selectedId is null:
   - UI must disable execution
   - and surface deterministic reason: "select a target"
4. UI does not bypass governance:
   - still calls existing governed execution entrypoint
   - still requires draft + lock + tool registry + flow + mode
5. Payload is deterministic:
   - operation + params + target_id

## Forbidden
- Any fallback guessing for target_id
- Any direct snapshot mutation
