# Tier 7.65 — Snapping System v2

## Purpose (LOCKED)
Provide deterministic snapping for placement and transform operations.

## Snap Modes
- none
- grid
- surface
- object

## Snap Config
{
  "mode": "none" | "grid" | "surface" | "object",
  "gridSize": number,
  "enabled": boolean
}

## Behavior

### Grid Snap
- rounds position to nearest gridSize
- applies per-axis independently

### Surface Snap
- raycast from object downwards
- align object base to hit surface
- uses world up (0,1,0)

### Object Snap
- snap object origin to nearest object origin within threshold
- threshold is deterministic constant (e.g. 0.5 units)

## Order of Application
1. raw delta
2. transform space
3. snapping (final stage)

## Determinism
- same input => same snapped output
- no randomness
- stable threshold behavior

## Invariants
- preview only before commit
- snapping does not mutate snapshot directly
- snapping is applied equally across multi-selection

## Forbidden
- mixing snap modes simultaneously
- physics-based snapping
- non-deterministic nearest calculations
