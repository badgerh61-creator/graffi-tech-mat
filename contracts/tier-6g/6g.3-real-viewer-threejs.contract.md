# Tier 6G.3 — Real Viewer (Three.js) + Picking (Asset-backed)

## Purpose (LOCKED)
Render snapshot scene objects in a real WebGL viewport and enable deterministic picking
that drives canonical UI selection state.

## Inputs
- GET /projects/{project_id}/snapshots/{snapshot_id}/scene (Tier 6G.1)
  - objects[] with { id, kind, asset_ref, transform }

## Asset Resolution
- If asset_ref starts with "asset:" then viewer must resolve it:
  - GET /assets/{asset_id}/url -> { url, type }
- Viewer loads GLB from the returned url.

## Viewer Responsibilities
1. Load the primary vehicle GLB (first object with asset_ref)
2. Render in a canvas (Three.js)
3. Picking:
   - click -> raycast -> nearest intersected mesh wins
   - selectionStore.setSelectedId(...) called deterministically

## Deterministic Selection Rule
On hit:
selectedId = "{object_id}::{mesh_name_or_uuid}"
- mesh.name preferred if present; else uuid
- object_id comes from scene index object.id

On miss:
clearSelection()

## Invariants
- Read-only (no backend writes)
- Deterministic mapping (same hit -> same selectedId)
- No tool execution here; selection is UI-only

## Forbidden
- snapshot mutation
- implicit "auto-select first mesh"
