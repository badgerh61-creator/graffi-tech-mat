# Tier 6S.5 — Scenario Library + Saved Runs + Compare Matrix (Lab Mode)

## Purpose (LOCKED)
Add scenario library + run tracking on top of simulation artifacts:
- Save named scenarios
- Execute scenarios to create telemetry artifacts
- List runs per project
- Compare multiple runs in a matrix

## Invariants (NON-NEGOTIABLE)
1. Scenarios are metadata objects (DB writes allowed).
2. Simulation execution remains job -> immutable artifact.
3. No snapshot mutation.
4. Deterministic:
   - same snapshot + same scenario + same engine_version -> same curves (engine responsibility).
5. Viewer/read paths are read-only.

## Entities
### Scenario
- id: int
- project_id: int
- name: string
- scenario_json: object
- created_by: int
- created_at: timestamp

### RunIndex
- id: int
- project_id: int
- snapshot_id: int
- scenario_id: int|null
- artifact_id: int
- engine_version: string
- created_by: int
- created_at: timestamp

## API (Additive)

### POST /simulation/scenarios
Body:
{
  "project_id": int,
  "name": "Baseline Accel",
  "scenario": { ... }
}
200:
{ "scenario_id": int }

### GET /simulation/scenarios?project_id=123
200:
{ "project_id": int, "scenarios": [ {id,name,scenario}... ] }

### POST /simulation/run
Body:
{
  "snapshot_id": int,
  "engine_version": "pseudo-v1",
  "scenario_id": int|null,
  "scenario": object|null
}
Rule: exactly one of scenario_id or scenario must be provided.
200:
{ "run_id": int, "artifact_id": int }

### GET /simulation/runs?project_id=123
200:
{ "project_id": int, "runs": [ {run_id, artifact_id, snapshot_id, scenario_id, engine_version}... ] }

### POST /simulation/compare/matrix
Body:
{ "artifact_ids": [int, int, ...] }  (min 2)

200:
{
  "artifact_ids": [...],
  "matrix": {
    "speed_avg_mps": { "1-2": number, "1-3": number, ... },
    ...
  }
}
(delta = B - A)

## Failure
- 401 unauthenticated
- 404 scenario/snapshot/artifact not found
- 422 invalid body

## Forbidden
- Any snapshot mutation
- Any artifact mutation
