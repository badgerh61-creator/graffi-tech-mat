# Tier 6S.3 — Advanced Telemetry Viewer (Read-only)

## Purpose (LOCKED)
Professional telemetry viewer:
- multi-curve overlay
- multi-run comparison
- curve toggle on/off
- deterministic ordering

## Inputs
Artifacts are loaded via existing:
GET /simulation/artifacts/{artifact_id}

## Features
1. Supported curves:
   - speed_mps
   - rpm
   - engine_temp_c
   - grip

2. Multiple artifacts can be loaded simultaneously.

3. Curve visibility toggle.

4. Deterministic ordering:
   - runs sorted by artifact_id asc
   - curve names sorted alphabetically
   - time axis is artifact-provided time_s

## Forbidden
- snapshot mutation
- artifact mutation
- re-running simulations from this panel (read-only)
