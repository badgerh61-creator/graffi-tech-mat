# Tier 7.20 — Pivot UI + Payload Binding

## Purpose (LOCKED)
Expose pivot controls for multiselect transforms and bind them into governed payloads.

## Pivot Modes
- bbox_center (default)
- world_origin
- custom (requires pivot {x,y,z})

## Payload Rules
1. If selection is multi (selected_target_ids length > 1):
   - include pivot_mode
   - if pivot_mode == custom, include pivot numeric xyz
2. If selection is single:
   - pivot_mode/pivot MAY be omitted (preferred)
3. Pivot values must be numeric and deterministic.

## Invariants
- UI-only control, no backend writes
- tool execution still governed via Tool Execution Adapter
