# Tier 7.25 — Rotation + Scale Gizmo Commits (Parity)

## Purpose (LOCKED)
Extend the Transform Gizmo commit path to support:
- ROTATE commits
- SCALE commits
in the same governed way as TRANSLATE.

## Invariants (NON-NEGOTIABLE)
1. Gizmo is UI-only and never mutates snapshots directly.
2. Commits execute only via governed endpoints:
   - /assistant/proposals/evaluate
   - /assistant/proposals/apply
3. Draft-only + lock-required + station/mode/flow enforced by kernel.
4. Payloads are deterministic given the same inputs.
5. Selection is the only source for target_id.

## Payload Shapes
### Rotate
{
  "tool": "ROTATE",
  "station": "geometry",
  "payload": {
    "target_id": "object::mesh_path",
    "axis": "x|y|z",
    "degrees": 15,
    "snap": { "enabled": true, "step_degrees": 5 }
  }
}

### Scale
{
  "tool": "SCALE",
  "station": "geometry",
  "payload": {
    "target_id": "object::mesh_path",
    "axis": "x|y|z|uniform",
    "factor": 1.2,
    "snap": { "enabled": true, "step_factor": 0.05 }
  }
}

## Forbidden
- Any direct snapshot mutation
- Any tool execution outside the adapter/commit controller
- Any guessed target_id
