# Tier 5.3 — Comparison View (Read-only)

## Purpose
Compare two snapshots (A vs B) for a given scenario using:
- tuning_state delta
- performance metrics delta (Tier 4.4)
- optional existing Tier 5.2 result ids (if available)

No snapshot mutation.
No tool execution.
No job required (can compute inline).

## API
GET /testing/compare?snapshot_a=ID&snapshot_b=ID&scenario_id=SID

## Output
{
  "scenario": {...},
  "a": { "snapshot_id": int, "tuning": {...}, "metrics": {...} },
  "b": { "snapshot_id": int, "tuning": {...}, "metrics": {...} },
  "deltas": {
     "tuning_delta": {...},
     "metrics_delta": {...}
  }
}

## Invariants
1) Deterministic: same inputs -> same output
2) Never writes to DB
3) Missing fields degrade safely
4) Viewer allowed
