# Tier 7.66 — History Timeline (Undo / Redo)

## Purpose (LOCKED)
Provide deterministic undo/redo navigation over snapshot history.

## Source of Truth
Snapshots are authoritative history.

## Timeline Model
{
  "snapshots": [Snapshot],
  "activeSnapshotId": number,
  "cursor": index
}

## Behavior

### Undo
- move cursor back by 1
- restore snapshot at cursor

### Redo
- move cursor forward by 1
- restore snapshot at cursor

### Restore
- direct jump to snapshot id
- becomes active snapshot

## Determinism
- same snapshot sequence => same timeline behavior
- no mutation of historical snapshots
- navigation is pointer-based only

## Invariants
- undo/redo never edits snapshots
- restore uses governed API
- timeline is derived, not stored server-side

## Forbidden
- modifying snapshot history
- branching timelines (future tier)
