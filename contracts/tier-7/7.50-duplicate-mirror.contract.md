# Tier 7.50 — Duplicate / Mirror

## Purpose (LOCKED)
Allow users to duplicate or mirror scene objects in a deterministic, governed way.

## Inputs
- selected object id
- optional duplicate offset
- optional mirror axis: x | y | z

## Tools (Governed)
SCENE_DUPLICATE_OBJECT
payload:
{
  "object_id": "obj-...",
  "offset": { "x": 0, "y": 0, "z": 0 }   # optional
}

SCENE_MIRROR_OBJECT
payload:
{
  "object_id": "obj-...",
  "axis": "x" | "y" | "z"
}

## Authoritative Storage
snapshot.body_state.objects : list[SceneObject]

SceneObject:
{
  "id": "obj-...",
  "kind": "model_ref" | "group" | ...,
  "name": "string",
  "asset_id": "asset-..." | null,
  "transform": {
    "pos": { "x": number, "y": number, "z": number },
    "rot": { "x": number, "y": number, "z": number },
    "scale": { "x": number, "y": number, "z": number }
  },
  "layers": ["default"],
  "enabled": true,
  "version": 1
}

## Duplicate Rules
- cloned object gets a new stable/generated id
- original object is unchanged
- material/decal references remain logically compatible
- duplicate name may be suffixed, e.g. "Car Copy"

## Mirror Rules
- mirror creates a new object, does not mutate original
- axis determines which transform component is mirrored
- minimal Tier 7.50 rule:
  - mirror position sign on chosen axis
  - preserve rotation/scale as-is
- later tiers may add true geometric mirror behavior

## Determinism
- same source object + same offset => same cloned data except generated id
- same source object + same mirror axis => same mirrored transform except generated id
- objects list sorted by id after apply

## Invariants
- no client-side snapshot mutation
- one governed commit per action
- remove/undo/history remain compatible
- no raw geometry duplication required

## Forbidden
- mutating source object in place
- shared mutable transform objects between original and clone
