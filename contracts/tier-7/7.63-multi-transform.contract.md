# Tier 7.63 — Multi-Transform Gizmo

## Purpose (LOCKED)
Allow transforming multiple selected objects using a shared gizmo.

## Selection Source
- uses multiSelectionStore.selectedIds
- primaryId defines pivot reference

## Pivot Rules
- pivot = primary object position (Tier 7.63)
- future tiers may support centroid or custom pivot

## Transform Modes
- translate
- rotate
- scale

## Behavior
- all selected objects move relative to pivot
- each object maintains relative offset from pivot
- transform preview occurs in viewer only
- commit writes per-object transform updates

## Tools (Governed)

SCENE_BULK_TRANSFORM
payload:
{
  "object_ids": ["obj-..."],
  "mode": "translate" | "rotate" | "scale",
  "delta": {
    "pos"?: { "x": number, "y": number, "z": number },
    "rot"?: { "x": number, "y": number, "z": number },
    "scale"?: { "x": number, "y": number, "z": number }
  }
}

## Apply Rules
- transform applied per object
- order of object_ids does not affect result
- missing objects ignored safely

## Determinism
- same selection + same delta => same result
- floating precision normalized

## Invariants
- no geometry mutation
- no merging of objects
- preview does not mutate snapshot
- one commit per transform action

## Forbidden
- applying transform directly in viewer state
- storing preview transforms in snapshot
