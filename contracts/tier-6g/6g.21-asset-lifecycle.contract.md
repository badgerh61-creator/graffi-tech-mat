# Tier 6G.21 — Asset Lifecycle Manager

## Purpose (LOCKED)
Control asset loading lifecycle to prevent race conditions and duplicates.

## Behavior

- each object has ONE active load
- old loads must not override new ones
- assets tracked by object_id

## Invariants

- no duplicate meshes
- no stale loads
- deterministic

## Forbidden

- applying outdated async results
- loading same asset multiple times uncontrolled
