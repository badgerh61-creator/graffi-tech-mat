# Tier 7.21 — Selection Bounding Box Metadata (UI Stub)

## Purpose (LOCKED)
Provide an optional selection_bbox metadata object in transform payloads
to support pivot visualization and future gizmo behaviors.

## selection_bbox shape
{
  "min": { "x": number, "y": number, "z": number },
  "max": { "x": number, "y": number, "z": number }
}

## Rules
1. selection_bbox is UI-provided metadata only (not authority).
2. It must be deterministic for the same selection set.
3. It is included only when selection is multi (>=2 targets) by default.
4. No engine dependency in this tier:
   - bbox can be computed via stable hashing of ids to placeholder coordinates.

## Invariants
- No backend writes
- Governed execution unchanged
