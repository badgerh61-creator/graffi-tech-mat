# Tier 6G.10 — Scene Graph Tree Panel (UI-only)

## Purpose (LOCKED)
Provide a deterministic scene tree UI so users can select objects/meshes without relying on viewport picking.

## Inputs
- GET /snapshots/{snapshot_id}/scene (Tier 6G.1)
  - objects[]: { id, kind, name?, asset_ref?, transform }

- Optional (UI-only): viewer mesh index cache populated by Three.js loader:
  - meshIndex[object_id] = list of mesh_path strings

## Outputs
- SceneGraphPanel renders:
  - list of objects (stable ordering)
  - per-object mesh list (if available) with expand/collapse
- Click behavior:
  - clicking object selects "{object_id}::"
  - clicking mesh selects "{object_id}::{mesh_path}"

## Determinism
- Objects sorted by (kind, id) lexicographically
- Mesh paths sorted lexicographically

## Invariants
- Read-only: no backend writes
- No snapshot mutation
- Selection updates are UI-only (selectionStore)

## Forbidden
- auto-select first node
- nondeterministic ordering
