# Phase 4.5 — Draft Finalization Flow

## Purpose
Define how draft snapshots are finalized into immutable completed snapshots.

---

## Snapshot States

- draft → editable
- completed → immutable
- failed → immutable (error state)

---

## Finalization Rules

- Only draft snapshots may be finalized
- Finalization creates a new completed snapshot
- Draft snapshot becomes closed (non-editable)
- Scene state hash is frozen
- No mutation after finalization

---

## API Endpoint

POST /projects/{project_id}/snapshots/{snapshot_id}/finalize

---

## Preconditions

- User authenticated
- User has edit permission on project
- Snapshot exists
- Snapshot.status == "draft"

---

## Success Response

```json
{
  "status": "completed",
  "snapshot_id": "uuid",
  "created_at": "iso-8601"
}
