# Tier 6G.18 — Transform Consistency Layer

## Purpose (LOCKED)
Ensure transforms are applied deterministically from snapshot state.

## Behavior

1. Viewer MUST:
   - apply transform from snapshot on load
   - reapply on snapshot change

2. No accumulation allowed

3. Transform is absolute (not delta)

## Format

{
  position: { x, y, z }
  rotation: { x, y, z }
  scale: { x, y, z }
}

## Invariants

- snapshot is source of truth
- viewer is read-only
- deterministic output

## Forbidden

- incremental transform updates
- mixing local/world inconsistently
