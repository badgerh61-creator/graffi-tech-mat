# Tier 7.7 — Transform Gizmo UI (Deterministic, Governed)

## Purpose (LOCKED)
Provide a visual transform gizmo (translate / rotate / scale) that:
- operates only on the active target
- produces governed tool invocations (Phase T)
- never mutates snapshot directly
- respects selection + station/mode + lock + draft-only constraints

## Invariants
1. Gizmo is a UI input device only. It never edits scene state directly.
2. Gizmo generates ToolInvocationPayloads, executed through the kernel path.
3. Gizmo is enabled only when:
   - activeSnapshot.status == "draft"
   - user has edit capability
   - user owns draft lock (Phase U.2)
   - station == "geometry" (or your canonical geometry station)
4. Axis constraints must be explicit:
   - axis: "x"|"y"|"z" or plane: "xy"|"xz"|"yz"
5. Snap is deterministic:
   - snapStep values are fixed (grid units)
   - applying the same drag input produces the same quantized delta

## UI Behavior
- If no active target: gizmo hidden
- If active target present but not editable: gizmo visible but disabled + reason
- Dragging a handle produces a "preview delta" (local only)
- On mouse up: commits a tool invocation:
  - TRANSLATE / ROTATE / SCALE
  - payload includes target_id + axis + delta

## Tool payload shapes (canonical)
Translate:
{
  "tool": "TRANSLATE",
  "station": "geometry",
  "payload": {
    "target_id": "panel-1",
    "axis": "x|y|z|xy|xz|yz",
    "delta": { "x": 1, "y": 0, "z": 0 },
    "snap": { "enabled": true, "step": 0.25 }
  }
}

Rotate:
{
  "tool": "ROTATE",
  "station": "geometry",
  "payload": {
    "target_id": "...",
    "axis": "x|y|z",
    "degrees": 15,
    "snap": { "enabled": true, "step_degrees": 5 }
  }
}

Scale:
{
  "tool": "SCALE",
  "station": "geometry",
  "payload": {
    "target_id": "...",
    "axis": "x|y|z|uniform",
    "factor": 1.2,
    "snap": { "enabled": true, "step_factor": 0.05 }
  }
}

## Forbidden
- Any direct snapshot mutation from frontend
- Any "apply" without lock or draft status
- Any non-deterministic snapping
