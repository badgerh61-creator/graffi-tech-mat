# Tier 7.27 — Live Preview Ghost (UI-only)

## Purpose (LOCKED)
Show a live "ghost" preview of the active target transform while dragging,
without mutating snapshots or writing to backend.

## Invariants (NON-NEGOTIABLE)
1. Preview is UI-only (no backend calls).
2. Preview never mutates snapshot state.
3. Preview is cleared when:
   - drag ends (commit happens)
   - drag is canceled (Escape)
   - selection changes / target disappears
4. Preview output is deterministic given the same drag input + settings.

## Data Model (Frontend)
PreviewState:
- target_id: string
- tool: "TRANSLATE" | "ROTATE" | "SCALE"
- payload: object (same shape as eventual commit payload, but for visualization only)

## Viewer Behavior
- When PreviewState is present:
  - clone target object group
  - apply transform to clone only
  - render with reduced opacity
- Original meshes remain unchanged

## Forbidden
- any snapshot mutation
- any backend persistence
