# Tier 7.77 — Gizmo Mode Switching

## Purpose (LOCKED)
Allow switching transform gizmo mode via hotkeys.

## Behavior

W → translate  
E → rotate  
R → scale  

Applies to active TransformControls.

## Invariants

- Only one mode active
- Works only when editor focused
- Does not break selection

## Forbidden

- multiple active modes
- changing mode without gizmo
