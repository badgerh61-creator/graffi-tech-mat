# Tier 6G.23 — LOD / Performance Strategy

## Purpose (LOCKED)
Maintain high performance by adapting rendering cost dynamically.

## Behavior

- reduce cost for distant meshes
- keep quality for close meshes
- avoid unnecessary rendering work

## Techniques

- frustum culling
- shadow optimization
- distance-based material simplification

## Invariants

- no flicker
- deterministic behavior

## Forbidden

- removing visible objects incorrectly
- breaking selection
