# Tier 6G.26 — Interaction Layer Cleanup

## Purpose (LOCKED)
Ensure deterministic and correct object picking in the 3D viewport.

## Behavior

1. Only visible + pickable objects can be selected
2. Closest valid hit MUST be selected
3. Clicking empty space MUST clear selection
4. UI overlays MUST NOT interfere with 3D picking

## Determinism
- Same click → same object

## Invariants
- No hidden objects selected
- No helper objects selected
- No stale object references

## Forbidden
- selecting by array index
- unfiltered raycast results
- non-deterministic hit selection
