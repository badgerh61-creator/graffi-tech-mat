# Tier 6G.7 — Camera Framing + Per-Object Focus

## Purpose (LOCKED)
Enable deterministic camera framing for:
- selected object (F key)
- double-click mesh (select + focus)
- entire scene fallback (no selection)

## Inputs
- loaded scene graph (Tier 6G.4+)
- selectionStore.selectedId (Tier 6G.5 uses objectId::mesh_path)

## Behavior
1) F key:
   - if selectedId exists: extract object_id and frame group "obj:<object_id>"
   - else: frame entire scene root
2) Double-click mesh:
   - pick mesh (same as click)
   - set selection
   - frame that object's group immediately

## Determinism
- framing uses bounding box of target object group
- camera distance derived from bounding box size (no random offsets)

## Invariants
- UI-only, no backend calls
- no snapshot mutation
- no implicit selection change on F
