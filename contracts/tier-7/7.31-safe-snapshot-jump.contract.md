# Tier 7.31 — Safe Snapshot Jump Glue (UI-only)

## Purpose (LOCKED)
Make snapshot navigation deterministic and safe across:
- history graph clicks
- undo/redo actions
- direct snapshot id jumps

## Required UI Effects on Navigate(toSnapshotId)
1) activeSnapshotId changes
2) selectionStore is cleared
3) gizmo preview is cleared
4) sceneIndex refetches for new snapshot
5) stale in-flight scene fetches must not overwrite newer navigation

## Invariants
- No backend writes
- No implicit selection set on navigation
- Navigation is single-source-of-truth (one function)

## Forbidden
- carrying selection across snapshots implicitly
- leaving preview ghost active after navigation
