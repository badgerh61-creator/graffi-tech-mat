# Tier 7.64 — Transform Spaces

## Purpose (LOCKED)
Allow transforms to operate in world, local, or pivot space.

## Modes
- world
- local
- pivot

## Definitions

### World Space
- axes aligned to global scene axes
- ignores object rotation

### Local Space
- axes aligned to object rotation
- per-object transform orientation

### Pivot Space
- axes aligned to pivot reference (primary object)
- used for multi-transform coordination

## Selection Source
- multiSelectionStore.selectedIds
- primaryId defines pivot orientation

## Behavior

### Translate
- world: move along global axes
- local: move along each object's local axes
- pivot: move relative to pivot orientation

### Rotate
- world: rotate around global axes
- local: rotate around object’s own axes
- pivot: rotate around shared pivot axes

### Scale
- world: uniform relative to world axes
- local: object-relative scale
- pivot: relative to pivot orientation

## UI
- transform space toggle (world / local / pivot)
- visible in ToolContextBar

## Determinism
- same mode + same delta => same result
- no ambiguity in axis interpretation

## Invariants
- no geometry mutation
- preview remains client-side only
- commit uses same delta semantics

## Forbidden
- mixing transform spaces in a single operation
- implicit fallback between modes
