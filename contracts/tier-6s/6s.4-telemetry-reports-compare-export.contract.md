# Tier 6S.4 — Telemetry Reports + Compare + Export (Read-only)

## Purpose (LOCKED)
Add lab-grade reporting utilities on top of telemetry artifacts:
- Summary metrics (per run)
- Run comparison (A vs B) with deltas
- CSV export for offline analysis

## Invariants (NON-NEGOTIABLE)
1. Read-only: no DB mutation beyond existing artifact/job writes.
2. Deterministic:
   - same artifact curves -> same summary/compare results
3. Snapshot remains immutable.
4. Artifact remains immutable.

## API (Additive)

### GET /simulation/artifacts/{artifact_id}/summary
200:
{
  "artifact_id": int,
  "snapshot_id": int,
  "engine_version": str,
  "summary": {
    "duration_s": number,
    "timestep_s": number,
    "speed_max_mps": number,
    "speed_avg_mps": number,
    "rpm_max": number,
    "rpm_avg": number,
    "engine_temp_max_c": number,
    "engine_temp_avg_c": number,
    "grip_min": number,
    "grip_avg": number
  }
}

### POST /simulation/compare
Body:
{ "a_artifact_id": int, "b_artifact_id": int }

200:
{
  "a_artifact_id": int,
  "b_artifact_id": int,
  "delta": {
    "speed_max_mps": number,
    "speed_avg_mps": number,
    "rpm_max": number,
    "rpm_avg": number,
    "engine_temp_max_c": number,
    "engine_temp_avg_c": number,
    "grip_min": number,
    "grip_avg": number
  }
}
(delta = B - A)

### GET /simulation/artifacts/{artifact_id}/export.csv
Returns CSV:
time_s,speed_mps,rpm,engine_temp_c,grip

## Failure Modes
- 401 unauthenticated
- 404 artifact not found
- 422 invalid compare body

## Forbidden
- Any mutation to snapshot or artifact
- Non-deterministic summary calculations
