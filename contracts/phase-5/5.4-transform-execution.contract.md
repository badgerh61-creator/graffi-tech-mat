# Phase 5.4 — Constraint-aware Transform Execution

## Purpose
Apply transforms only after constraint validation passes.

---

## Execution Rules

- Only draft snapshots may be mutated
- Constraint validation MUST pass
- Execution is atomic
- Execution produces a command record
- Execution updates scene state deterministically

---

## API Endpoint

POST /projects/{project_id}/snapshots/{snapshot_id}/execute-transform

---

## Request Body

```json
{
  "target_id": "string",
  "operation": "translate | rotate | scale",
  "params": {},
  "constraints": []
}
```

---

## Success Response

```json
{
  "applied": true,
  "command_id": "uuid"
}
```

---

## Failure Response

```json
{
  "applied": false,
  "violations": [...]
}
```

---

## Forbidden

- Executing without validation
- Executing on completed snapshots
- Silent geometry correction
