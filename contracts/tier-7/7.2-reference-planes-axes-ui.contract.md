# Tier 7.2 — Reference Planes & Axes UI (Read-only)

## Purpose (LOCKED)
Expose authoritative reference frames (planes + axes) to the Studio UI so users can:
- see global axes
- see available reference planes
- select an active plane for snapping (UI-local only in 7.2)
without mutating snapshots.

## Invariants (NON-NEGOTIABLE)
1. Read-only: calling Tier 7.2 endpoints must not change DB or snapshot.
2. Deterministic: same snapshot -> same frames output.
3. Viewer-accessible: any user who can view snapshot can read frames.
4. Missing model data must degrade gracefully (defaults), never crash.

## API (Additive)
GET /snapshots/{snapshot_id}/reference-frames

### Success 200
{
  "snapshot_id": int,
  "axes": {
    "x": {"label":"X","unit":"m"},
    "y": {"label":"Y","unit":"m"},
    "z": {"label":"Z","unit":"m"}
  },
  "planes": [
    {"id":"world_xy","label":"World XY","normal":[0,0,1],"origin":[0,0,0]},
    {"id":"world_yz","label":"World YZ","normal":[1,0,0],"origin":[0,0,0]},
    {"id":"world_xz","label":"World XZ","normal":[0,1,0],"origin":[0,0,0]}
  ],
  "defaults": {
    "active_plane_id": "world_xy"
  }
}

### Failure
- 404 snapshot not found
- 401 unauthenticated

## Forbidden
- No mutation
- No plane creation/editing (future tier)
- No snapping logic executed server-side (future tier)
