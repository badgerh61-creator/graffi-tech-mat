# Tier 7.47 — Scene Outliner (Objects list + visibility/layer toggles + remove object)

## Purpose (LOCKED)
Provide a real editor outliner for scene objects:
- list all body_state.objects
- select object from outliner
- toggle enabled/visibility
- toggle membership in layers
- remove object from scene

## Storage (Authoritative)
snapshot.body_state.objects: list[SceneObject]

SceneObject:
{
  "id": "obj-...",
  "kind": "model_ref" | "primitive" | ...,
  "name": "string",
  "asset_id": "asset-..." | null,
  "transform": { ... },
  "layers": ["default", ...],
  "enabled": true,
  "version": 1
}

## Tools (Governed)
SCENE_SET_OBJECT_ENABLED
payload:
{
  "object_id": "obj-...",
  "enabled": true|false
}

SCENE_SET_OBJECT_LAYERS
payload:
{
  "object_id": "obj-...",
  "layers": ["default", ...]
}

SCENE_REMOVE_OBJECT
payload:
{
  "object_id": "obj-..."
}

## Read Behavior
- Outliner reads activeSnapshot.body_state.objects
- deterministic order: sort by object.id unless backend already guarantees sorted list

## Viewer Behavior
- enabled=false objects are not rendered
- layer filtering is viewer-side and deterministic

## UI Behavior
- clicking an outliner row selects that object
- toggle enabled sends one governed commit
- layer edits send one governed commit
- remove sends one governed commit
- no optimistic mutation required

## Invariants
- no direct client snapshot mutation
- one commit per action
- deterministic object ordering
- selection from outliner uses existing selectionStore
