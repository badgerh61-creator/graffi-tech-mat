# Tier 6G.6 — Scene Layers + Pick Filters (UI-only)

## Purpose (LOCKED)
Add UI scene layers and pick filters so users can:
- toggle visibility by object kind
- control which kinds are pickable (raycast targets)
- optionally "ghost" kinds via opacity

## Inputs
- scene index objects[] with { id, kind, asset_ref, transform }

## Outputs
- UI-only LayerState in frontend
- viewer uses LayerState to:
  - show/hide objects by kind
  - include/exclude objects in pickables
  - apply opacity rules

## LayerState (canonical)
kinds: Record<kind, { visible: boolean, pickable: boolean, opacity: number }>
Defaults:
- visible=true
- pickable=true (helpers default false)
- opacity=1.0

## Invariants
- Read-only: no backend writes
- Deterministic defaults
- Picking respects pickable flag (non-pickable kinds never win)
- Clearing selection when selected object becomes hidden is allowed

## Forbidden
- snapshot mutation
- backend persistence in this tier
