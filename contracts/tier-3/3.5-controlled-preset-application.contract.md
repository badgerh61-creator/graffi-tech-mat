# Tier 3.5 — Controlled Preset Application

## Purpose
Apply a decor preset to a draft snapshot in a governed way.

---

## Preconditions

- Snapshot.status == "draft"
- User holds draft ownership lock
- Tool = APPLY_DECOR_PRESET
- Station = PANEL or DECOR station
- Flow graph allows mutation
- Preset exists
- Preset version valid

---

## Behavior

- Creates new child draft snapshot
- Parent snapshot remains unchanged
- Preset version recorded
- Material references copied as references (not duplicated)
- Layout refs applied deterministically

---

## Snapshot Metadata Additions

snapshot.applied_presets[]:
    - preset_id
    - preset_version
    - applied_by
    - applied_at

---

## Failure Modes

| Condition | HTTP |
|-----------|------|
| Not draft | 409 |
| Not owner | 403 |
| Tool not allowed | 403 |
| Flow invalid | 409 |
| Preset not found | 404 |

---

## Audit

Emit:
action = "snapshot.decor_preset_applied"
resource_id = new_snapshot_id
extra:
    parent_snapshot_id
    preset_id
    preset_version
