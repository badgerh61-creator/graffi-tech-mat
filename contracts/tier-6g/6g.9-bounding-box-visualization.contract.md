# Tier 6G.9 — Bounding Box Visualization (UI-only)

## Purpose (LOCKED)
Render a deterministic bounding box outline for the current selection to improve
editing clarity (anchor feedback, target confirmation).

## Inputs
- selectionStore.selectedId
  - format: "{object_id}::{mesh_path}" OR "{object_id}::" (object only)
- viewer scene graph:
  - object groups named "obj:{object_id}"
  - meshes inside loaded GLBs

## Behavior (Canonical)
1) When selectedId is null:
   - no bounding box shown
2) When selectedId is "{object_id}::" (object selected):
   - draw bounding box around the object group "obj:{object_id}"
3) When selectedId includes mesh_path:
   - attempt to find the mesh node deterministically by mesh_path
   - if found: draw box around that mesh
   - if not found: fallback to object group box

## Determinism
- box is derived from THREE.Box3().setFromObject(target)
- uses THREE.Box3Helper with a fixed style (no randomness)

## Invariants
- UI-only: no backend writes
- No snapshot mutation
- Box helper must be disposed/replaced on selection changes
- No ghost helpers left behind on snapshot rebind

## Forbidden
- auto-selection
- mutating scene transforms
