# Tier 3.4 — Decor Preset Library (Culture-Aware)

## Purpose
Expose curated decor presets grouped by cultural styling packs.

---

## Decor Preset Fields

- id
- name
- description
- culture_pack (string)
- version
- category (interior | exterior | full)
- material_refs[]
    - material_id
    - target_zone (seat | roof | panel | trim | dash | exterior-panel)
- layout_refs[]
    - zone
    - configuration_key
- tags[]
- created_at
- created_by

---

## Behavior

- GET /decor-presets
- Filterable by culture_pack
- No mutation endpoints
- No snapshot creation
- No auto-application

---

## Forbidden

- Applying preset
- Editing preset
- Inline draft mutation
- Material duplication inside preset
