# Tier 7.48 — AAA Camera Navigation

## Purpose (LOCKED)
Upgrade the viewport camera so the editor feels like a professional DCC/CAD tool.

## Features
- orbit around target pivot
- pan
- dolly/zoom
- frame selected object
- frame full scene
- camera preset views:
  - front
  - back
  - left
  - right
  - top
  - bottom
  - iso

## Inputs
- scene root bounding box
- selected target id (object or mesh)
- current camera state

## UI Behavior
- camera controls are viewer-only
- camera changes do not mutate snapshot
- frame selected uses authoritative visible scene object bounds
- frame scene uses authoritative visible scene bounds

## Determinism
- same scene + same selection + same frame command => same camera result
- camera reset after snapshot navigation must be explicit, not accidental
- disabled/hidden objects do not contribute to bounds

## Invariants
- no backend writes
- no snapshot mutation
- no selection mutation from camera actions
- camera controls must survive scene rebuilds safely

## Optional Keys / Hotkeys
- F = frame selected
- Shift+F = frame scene
- numeric or button presets for front/top/side/iso
